# 0.9.4：工程删除保护与首次启用修复

## 修复内容

1. 工程删除现在经过主进程的运行状态检查与独占维护租约。Unity 正在使用工程、素材正在导入或其他维护任务占用时，删除会被拒绝。租约覆盖回收站异步操作和失败回退，完成或异常均释放；持有租约期间不能开始新导入或重复删除。界面同时阻止重复确认，并解释运行中的工程需要先关闭 Unity。
2. 普通启动会进入自动启用流程，修复缺少配置时被 enabled=false 提前拦截的问题，符合现有 R20 设计。安全模式仍不初始化项目管理。初始化结束会通知项目页与设置页刷新，避免首次打开时停留在旧的未启用状态。
3. 固定默认目录 `%APPDATA%\Atrium` 的初次检查、真实路径检查、状态读取使用相同规则。系统盘例外只针对主进程确定的精确默认目录；IPC 的 systemDefault 标志不能放行任意路径。素材库、已知工程和安装目录的隔离检查保留，并按真实路径再次验证。已有有效的自定义数据根保持原配置。

应用和锁文件版本同步为 0.9.4，没有数据库 schema 变更。
