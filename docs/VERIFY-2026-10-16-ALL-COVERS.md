# 全库封面更新验收

日期：2026-10-16；基线 `e61c1e6`；分支 `codex/all-cover-update`；版本 v0.7.0。

## 实现范围

- 主入口一次点击启动全库后台队列；当前筛选和所选素材作为可选范围。全库包含成员，不受界面分页限制，附属资源排除。
- 唯一且完整、无警告的候选自动生成保存；多个候选或不完整结果进入集中选图，每页最多八张，点击图片立即应用并记住关联。
- 商品图、手动上传图保护；已有自动图按原关联重新生成，包括已保存的 Unity 场景物品。
- App 层持续显示任务状态；切页、收起面板不停止；显式停止、仅重试失败项和条件撤销独立提供。
- SQLite V9 备份每次覆盖前的完整关联和图片；缓存维护保护撤销引用，后续手动改图不被撤销覆盖。

## 已验证的边界

新增回归覆盖：超过 500 条、合集成员、分组变体、商品图与上传图、唯一/多候选、警告/截断、无模型、串行运行、取消与晚到响应、源文件变化、依赖选择变化、预览过期、筛选搜索一致性、页面切换、重复操作和完整关联恢复。

旧封面模块开工基线为 239 项通过。独立审阅发现依赖变化后旧候选可保存、筛选任务未沿用索引搜索两项 P2，均先复现失败再修复，审阅复核通过。

实际 React／Electron 界面验收通过五组场景：一键全库和后台浏览、八张候选与晚到响应、图片点击即保存与自动前进、失败重试/停止/条件撤销、筛选/所选范围与错误恢复。验证包含生产组件、store、样式和语言，外部任务端点受控；截图已实际查看，不能将其当作真实 GPU 拍摄证据。

首次完整构建在并行负载下有一项原有 5 万条性能断言失败：0.648 ms/条，原阈值 0.6。保持源性能实现、阈值和全部测试不变，最终使用 `VITEST_MAX_FORKS=1`、`VITEST_MIN_FORKS=1` 运行完整构建；性能三次采样为 0.596 / 0.810 / 0.574 ms/条，按原测试规则取最小值后通过。31 项跳过需要显式提供的真实数据或可选环境，不计为通过。

真实验收使用 Unity **2022.3.22f1**。唯一预制体自动保存，多预制体保持原图直到用户选择；候选图由实际 GPU 输出，Electron 解码后为 320×240，所选图与保存图的哈希核对一致。生产服务重建后沿用持久关联，精确撤销恢复旧图片及关联，后续手动上传受到保护；缓存清理后撤销图片仍可读取。原始合成素材包 SHA-256 不变，素材导入记录为 0，内部工程登记数为 0。

这验证了独立合成方块与 Standard 材质的真实流程；没有将用户头像、所有第三方着色器或完整应用退出后自动续跑视为已验证。已保存 Unity 场景对象、取消竞争与搜索边界另由受控回归验证。
