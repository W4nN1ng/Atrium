> 其余全是文字按钮；危险操作都有 Modal 二次确认；组件不直接碰 IPC。

## 2. 这一轮改了什么

1. **空状态的「添加项目」从实心降为文字**：它和头部的「新建项目」同屏时会出现两个主按钮。
2. **事件订阅收进 api 层**：`DeepLinkHost` / `VpmMaintenancePanel` 原来直接 `window.a.on(...)`，
   现在走 `vpmApi.onDeepLink()` / `vpmApi.onBackupProgress()`。
3. **新增三条硬规矩的测试**（`tests/renderer/vpm-ui.spec.ts`）：
   - `renderer/vpm/components/**` 里不许出现 `window.a`；
   - 渲染层不许 `import 'electron'`；
   - 项目页主屏（第一个 `<Modal` 之前）**只能有一个** `variant="accent"`。

## 3. 按钮纪律（以后照这个判）

- 一屏一个实心按钮；其余用文字按钮。
- 实心按钮 = 这一屏"用户来这儿干什么"。
- 模态框是独立的一屏，里面可以有自己的实心确认按钮。
- 危险操作：Modal + 一句后果说明，**不弹两层**。
- 列表行内最多三个按钮（打开 / 管理 / ⋯），其余进 `⋯`。

## 5. 已知限制

- 包图标没有远程抓取，只有失败时的首字母回退；本轮没有新增图标管线（不做重型 UI）。
- 设置页的「模板」编辑（新建/编辑/复制模板）仍缺 UI——服务层已就绪（P5-A），
  但那是新功能，P8-A 不新增功能。
- 深链只在开发态注册（`electron.exe`），装包后才由系统唤起；没有真机点过。
