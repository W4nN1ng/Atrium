# 0.9.7：共享素材回收、完整搜索和输入法修复

统一修复 0.9.6 第二轮检查中的 1–3 项。

## 结果

1. **共享文件和独立素材受保护**：回收前检查整个逻辑子树及其他素材的文件引用。压缩包中的单个子项如果与合集或兄弟共用文件，会拒绝回收并显示原因；目录内有已拆出、独立登记的素材时，也会保留该目录。检查同时覆盖来源路径、大小写及 junction 别名、暂时缺失的成员路径。没有外部引用的完整合集仍可回收；重复选择父子项时只移动一次，同时清理子树的记录与索引。不会为删除一个子项而改写压缩包。
2. **搜索保留完整候选**：取消 SQL 筛选前的 2,000 项裁剪，先获取完整匹配，再做分类、集合、分组和分页。完整 ID 集合通过一个 JSON 参数传给 SQLite，避免用数万个独立占位符导致参数超限。普通限量搜索调用保留原接口。
3. **输入法确认不触发保存**：路径框同时检查组合输入状态、原生 isComposing 和兼容键码 229。确认候选词时保持焦点；组合结束后普通 Enter 和失焦保存继续有效。
