# 0.9.6：素材详情、搜索、分页与路径输入修复

本次统一修复 0.9.5 检查中确认的 1–5 项，完成全部验证后一起提交。

1. **切换素材时清空旧详情**：开始读取新素材即移除旧详情和操作按钮；通过请求序号及目标 ID 双重检查，忽略迟到的结果。切换页面或关闭详情后不会重新出现旧内容，同一个素材的较早请求也不能覆盖较新请求。
2. **重命名后立即更新搜索**：素材名与组名在同一数据库事务中保存，再同步增量搜索索引。共享组名的其他变体也更新别名，避免只更新当前卡片。
3. **搜索覆盖合集子素材**：有搜索词且未明确限定范围时，搜索默认包含子素材；普通浏览仍显示顶层，显式的顶层或父合集范围继续生效。索引尚未就绪时的 SQL 搜索使用同样范围。
4. **列表支持继续加载**：首批 400 项，随后可滚动到底自动加载或点击「加载更多素材」，网格与列表共用分页。排序增加 ID 作为同时间戳的稳定次序。刷新保留已加载数量，切换搜索或筛选重置分页；并行请求、过期请求和失败重试均有保护。「全选」仍选择当前已加载的素材。
5. **路径可以连续编辑**：路径行不再以正在输入的文本作为组件标识。输入在本地保留，失去焦点或按 Enter 后保存，避免逐字请求和焦点丢失。工程根目录与监视目录使用同一组件。
