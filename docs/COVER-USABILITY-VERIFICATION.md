# 封面使用流程验证（提案 1、2、5）

本轮基于 `4d27173`，完善依赖工程推荐、候选物品选择，以及进度与失败重试。未扩展多角度自动拍摄、缓存架构或逐项缺失资源诊断。

## 已实现的行为

- 预览前只读检查已登记工程的 lilToon 包、版本及可读取的 shader。已有素材保留其保存的依赖，包括不使用外部依赖；新素材优先使用上次成功保存的选择，仅有一个可用工程时推荐它。多个工程不任意选择，失效的已有选择保留并提示。只在成功保存素材包封面后记忆；失败、取消及本地图片操作不改变记忆。
- 检查完成前不自动启动查找；选中的依赖在准备资源及启动独立 Unity 前再次检查。依赖检查不启动编辑器，也不写源工程。
- 候选预制体优先，标注预制体和原始模型，保留款式；支持名称、路径、包内来源搜索及类型筛选。维持先显示 8 项、最多 50 项的边界，不自动选择或保存。
- 显示实际阶段及已用秒数，保留可获得的工作条目数量，不估算完成百分比。查找、当前预览及失败候选均可重试，显示操作建议，技术详情默认折叠。
- 筛选保留已完成的图片，取消隐藏项的待处理工作。手动生成后隐藏目标时取消该请求，晚到成功或失败均不恢复图片、启用保存或改写错误提示。保存期间锁定控件，停止后台候选生成。

## 自动与界面验证

- 完整 `npm test -- --maxWorkers=2 --minWorkers=1`：132 个文件通过、10 个文件条件跳过；1862 项通过、31 项条件跳过，无失败。跳过项仍依赖外部样本、真实库或外部服务，不能视为通过。
- `npm run typecheck`、Electron Vite 生产构建及 `tools/check-worker-deps.cjs` 通过。
- Unity 2022.3.22f1 自带 Roslyn 编译桥接通过；该项仅证明 API 和编译兼容。
- `tools/verify-cover-usability-ui.cjs`：10 组实际 React / Electron / IPC 场景通过，包括检查门控、推荐及手动覆盖、8/50 分页、搜索和类型筛选、用时、三类重试、保存锁定、旧关联，以及搜索／类型 × 晚到成功／失败。外部响应受控，不作为真实 Unity 渲染证据。
- 原有 `tools/verify-package-cover-ui.cjs`、项目候选回归及保存竞态回归通过。保存竞态验证已有后台请求在显式保存期间被取消，同时只保存一次。
- `tools/verify-cover-ui.cjs` 连接隔离 Unity 工程的实际生产界面首轮及重启均通过，覆盖已有工程中的对象选择、搜索、角度、保存、恢复、取消、本地图片、批量及手动图片保护。

## 实际原包验收

使用已构建的生产主进程、preload、界面及隔离 SQLite，从合法副本的巧克力、百奇 ZIP 创建全新预览工程，由实际 Unity 2022.3.22f1 和 lilToon 2.3.4 渲染。

`tools/verify-package-cover-integration.cjs` 首次运行及重启均通过：

- 在查找前自动推荐唯一可用依赖，第二份素材沿用成功保存的记忆；重启后设置和素材关联仍存在。
- 预制体排在原始模型之前，显示可解码图片，仍需明确选择及保存。实际截图区分带材质的百奇预制体和未配置的白色原始模型。
- 角度调整、卡片图片、恢复原图、取消、批量更新、手动图片保护及重启通过。
- 两份原 ZIP、依赖 shader 资源及参照元数据的前后 SHA-256 相同。导入记录为 0，预存资源清单为 0，导入目标保持为空，内部预览工程不登记到用户工程列表。
- 两阶段退出后自有 Unity 进程均为 0。未启动或编辑用户的改模工程，未在用户生产数据库执行测试。

第三方资源、隔离数据库、图片、完整哈希及日志保留在 Git 忽略的验证目录，不随仓库提交。建议使用说明见 [Unity 物品封面](UNITY-COVERS.md)。
