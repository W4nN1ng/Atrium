# Unity 自动连接与导入目标

适用于源码及安装包 v0.6.0。当前已验证 Unity 2022.3.22f1；自动连接支持 Unity 2022.3 工程。

## 使用流程

1. 打开 Unity 工程，并保持 Atrium 运行。缺少连接插件时，Atrium 自动安装到工程的 `Packages/com.avca.bridge`；收到 Unity 实际响应后显示「已连接」。
2. 找到素材，点击带工程名的导入按钮。只打开一个可用工程时，无需另选目标；多个工程同时运行时，沿用你明确选择的工程，否则在这次导入开始前选择一次。
3. 按现有设置确认导入、处理冲突。连接准备期间可以取消等待；Unity 忙碌时，已提交的操作继续使用原有队列。

打开工程只准备连接，不会自动导入素材。**如果这个工程是由 Atrium 启动的，它会立即成为当前导入目标**（不必等桥接就绪）；随后双击素材就导入它。你显式选择另一个目标时，以你的选择为准；启动失败、工程关闭或移除会清除这个绑定。一次任务及其后续批次始终使用最初确定的工程；中途切换目标、打开其他工程或关闭原工程，均不会把已有任务转投别处。

VPM 包管理也遵守同一目标：启动工程先绑定目标再启动 Unity；“打开 Unity”与“双击素材”不会指向不同工程。包事务只在该工程未运行、且没有素材导入进行时才开始。

## 连接状态与恢复

- **正在准备连接／正在连接：** 插件安装完成不代表 Unity 已响应；首次编译可能需要等待。导入前的连接等待最多 180 秒，取消只撤销这次导入等待，不卸载已安装的插件。
- **连接失败：** 在「当前工程」点击「重试连接」，或展开详情查看原因。自动连接不会每轮重复安装失败的插件。
- **未打开 Unity：** 打开工程后会重新检测。Unity 在播放、编译或导入资源时，素材操作会排队等待可执行状态。
- **已停用：** 工程高级选项可卸载并停用自动连接；重试可重新启用该工程。「设置 → Unity → 高级连接选项」可关闭全局自动连接。
- **版本不支持／路径异常：** 不会自动安装。当前支持范围为 Unity 2022.3；目录链接或损坏的内部预览工程标记会阻止自动写入。

已有连接插件直接复用，不强制覆盖手动修改。封面预览使用的内部工程不会成为导入目标，也不会进入普通自动安装流程。

## 本次边界

保留现有冲突确认、导入前确认偏好、备份、导入历史和撤回规则。封面功能及其 Unity 渲染代码未改动。
