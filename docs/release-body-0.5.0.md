**Atrium 是面向 VRChat 创作者的本地素材管理工具。** 在一个 Windows 桌面应用中完成素材收集、分类检索和 Unity 导入，便于管理模型、服装、贴图与插件。

**v0.5.0 新增物品封面、导入历史和手动数据库备份，并改善日文文件名识别与合集判断。**

## 本次更新

### 物品封面

- **从素材包生成封面：** 打开素材详情，点击「编辑封面」即可预览包内模型并拍成封面图。支持原始 `.unitypackage`、含 `.unitypackage` 的 ZIP，以及含包的素材目录。适用于没有商品预览图的道具、服装和合集成员。
- **从 Unity 工程生成封面：** 选择已导入该物品的工程，自动查找对应的预制体和模型并逐张生成候选图。依据资源标识匹配，不按名称猜选，也不会把尚未导入的物品安装进工程。手动导入的物品可通过原包的资源清单匹配。
- **依赖与渲染：** 封面使用本机 Unity 2022.3 的独立工程渲染，工程无需提前打开。会读取已连接工程中的 lilToon 渲染资源，并记住成功保存时的依赖选择。预览不修改源工程、不安装桥接，也不产生导入记录。
- **候选与调整：** 预制体优先展示，先显示 8 项、最多 50 项，可按名称、资源路径或包内来源搜索，并筛选预制体或原始模型。选择角度和深浅背景后重新拍摄，确认前卡片不会变化。
- **本地图片与恢复：** 支持 PNG、JPEG、WebP、BMP，单文件最大 8 MB，无需 Unity 在线。「恢复原始封面」可移除自定义封面，恢复第一次覆盖前的图片。
- **批量更新：** 选中多张卡片后点击「更新所选封面」，按已保存的来源、对象、角度和背景串行更新；改用本地图片的素材会跳过。

### 导入历史与撤回

- **按批次查看：** 「当前工程 → 导入历史」可按全部工程或单个工程筛选，按完整批次分页查看包名与状态，确认后撤回。历史保存在数据库中，重启后仍可读取，超过 200 条的批次不会被截断。
- **撤回保护：** 较新的导入涉及同一资源时，会先处理相关的新批次；没有重叠的旧批次可单独撤回。后台在执行前会再次检查，旧的单包与批量撤回入口同样受此保护。
- **如实报告不完整：** 备份被清理、清单损坏或还原不完整时不再报告成功，而是显示「撤回不完整」并停下整批操作，提示需要手动检查工程。

### 数据库备份

- **手动备份：** 「设置 → 维护 → 备份数据库」通过系统保存窗口选择位置，完成后显示文件路径与大小；取消不会显示保存成功。
- **备份内容：** 包含素材索引、分类、集合和导入历史。不包含素材原文件、缩略图、Unity 工程和导入前文件备份。
- **写入安全：** 采用 SQLite 在线备份，包含已提交但仍在 WAL 中的数据；先写临时文件再发布到目标，失败时保留已有目标文件。

### 分类与文件名识别

- **日文文件名：** 增加 EUC-JP 解码候选，修复未标记编码的日文文件名被当作 GBK 后部分汉字损坏的情况。
- **说明与文档目录：** 说明、文档、教程和配图目录不再因为文件数量被展开为商品，嵌套素材筐使用相同规则。
- **临时素材筐误判：** `Templates.2`、`Temporary Clothing` 不再因为 `temp` 前缀被当作临时素材筐。

## 主要功能

### 素材收集与分类

- 支持拖放、资源管理器「发送到 Atrium」、监视文件夹和目录扫描。
- 支持 ZIP、RAR、7z、Unity Package 及嵌套压缩包；可选择处理部分成员。
- 支持加密压缩包，在用户选择记住密码后加密保存。
- 结合文件名、包内路径和内容特征给出分类建议，展示判断依据。
- 识别合集、适配模型与版本，将同一商品的多个变体归并展示。

**素材分析与分类在本地完成。** 判断不明确的素材会提示你确认，或加入「待复核」列表。「拿不准就问」指人工确认分类结果；当前版本不调用在线 AI 模型，设置中的模型相关选项尚未参与分类流程。

### 检索与素材库管理

- 支持拼音、假名、罗马字、模型别名及自定义别名搜索。
- 提供卡片与列表视图、素材封面、物品封面编辑和集合管理。
- 归档模式下，分类调整前可预览文件移动与覆盖情况，完成后支持整批撤回。
- 库检查可列出重复素材、相似封面、未登记文件和失效记录。
- 「设置 → 维护」提供索引重建、归并检查及手动数据库备份。
- 素材库中的文件删除使用系统回收站，多种库操作支持 `Ctrl+Z` 撤销。

### Unity 集成

- 发现本地 Unity 工程，并根据与集合的匹配结果切换视图；匹配不明确时显示提示。
- 导入前检查资源冲突，支持备份被覆盖的文件；批量导入显示进度。
- Unity 处于播放模式或忙碌状态时，导入请求排队等待。
- 「当前工程 → 导入历史」可按批次查看并撤回经由 Atrium 执行的导入。
- 素材详情可查看经由 Atrium 导入的工程记录，最近一次批次提供快捷撤回入口。
- 支持从素材包或已导入的 Unity 工程生成物品封面。
- 支持托盘常驻和 `Ctrl+Alt+A` 素材投放窗口。
- 界面支持简体中文、English 和日本語。

## 快速开始

1. **选择素材库。** 新建素材库可选择独立文件夹；已有素材库可选择「接管这个库」，先登记文件，不移动或重命名原有内容，并关闭高置信度自动归档。
2. **设置素材来源。** 可指定需要监视的下载文件夹，也可随时手动添加素材。
3. **连接 Unity 工程。** 勾选需要连接的工程。桥接安装到 `Packages/com.avca.bridge`，安装过程不修改 `Assets` 或场景。
4. **选择启动偏好。** 按需要决定是否开机启动，默认关闭。

配置素材库后，将素材拖入收件箱，检查分类建议并确认入库。导入 Unity 时，先选择已连接的目标工程，再选择资源并确认导入。衣柜、道具、插件这类没有预览图的素材，可在素材详情点击「编辑封面」生成图片。向导可稍后继续，其余设置可在设置页调整。

## 使用说明与已知限制

| 项目 | v0.5.0 的行为 |
| --- | --- |
| 本地处理 | 素材分析与分类无需联网，素材不上传至云端。 |
| 物品封面环境 | 需要本机可用的 Unity 2022.3、许可证和 GPU。没有 Unity 时仍可选择本地图片。 |
| 物品封面范围 | 已验证 Unity 2022.3.22f1 与 Built-in 渲染管线。支持 MeshRenderer 和 SkinnedMeshRenderer；隐藏的子物体不参与拍摄，LOD 使用第一层网格。不运行道具脚本、Animator、MA/NDMF 构建或 VRChat 交互逻辑，因此封面不是游戏内效果验证。URP/HDRP、粒子、动画和自动下载依赖尚未支持。 |
| 素材包预览格式 | 素材包模式支持 ZIP 与 `.unitypackage` 的静态 Built-in 资源；RAR、7z、加密和嵌套压缩包需要先整理为受支持的包，或改用工程模式。 |
| 素材包预览上限 | 原包上限 512 MiB、解压资源 2 GiB，最多 32 个包、20,000 个条目和 10,000 个资源标识，读取截止 45 秒。 |
| 预览缓存 | 应用保留至多三个已准备的预览工程；未清理的缓存在后续预览前清理。生成图片为预览用途，最长边 320 像素。 |
| 导入历史撤回 | 依赖对应工程和桥接在线，只处理导入记录中的资源，不保证恢复后续的手动修改。撤回后可能保留空目录。 |
| 数据库备份范围 | 副本不包含素材原文件、缩略图、Unity 工程和导入前文件备份；本轮没有增加从备份恢复数据库的界面。 |
| 索引模式 | 只登记素材，文件保留原有位置。 |
| 工程记录 | 只记录经由 Atrium 执行的导入，不提供 Unity 工程全部资源的清单。 |
| 重复与相似检测 | 重复素材需手动选择处理，相似检测仅比较封面图。 |
| 搜索范围 | 支持已知及自定义别名，不提供任意中文名称的日语读音转换。 |
| 文件名编码 | 无编码标记的文件名可能存在识别歧义；已增加 EUC-JP 候选，特别短的纯汉字名称仍需人工核对。 |
| 数据目录 | 应用数据默认位于 `C:\Users\你的用户名\AppData\Roaming\A`，暂不提供界面迁移；素材库可选择其他磁盘。 |
| 密码保存 | 密文保存于本地数据库，解密依赖当前 Windows 账户与设备，换机后可能无法解密；数据库备份中的密码密文同样如此。 |

拖放内容缺少可读取的本地路径时，可先保存或解压到本地，再使用「收件箱 → 选择文件…」或资源管理器「发送到 Atrium」。

**兼容性：** 已验证环境为 Windows 11 + Unity 2022.3.22f1；Windows 10 尚未完成实机验证。

**验证范围：** 已完成自动化测试、构建检查及隔离环境中的界面与后台流程验证，物品封面另有独立 Unity 工程的实际渲染验收。真实头像的 SDK 构建与上传、VRChat 游戏内效果、系统热键冲突、资源管理器拖放和跨盘故障场景仍需实机验证。详情见 [封面使用说明](https://github.com/W4nN1ng/Atrium/blob/main/docs/UNITY-COVERS.md)、[导入历史与备份说明](https://github.com/W4nN1ng/Atrium/blob/main/docs/FIXES-2026-10-11-IMPORT-RECOVERY.md) 和 [验证记录](https://github.com/W4nN1ng/Atrium/blob/main/docs/VERIFY-UNVERIFIED.md)。

## 数据位置

| 内容 | 默认位置 |
| --- | --- |
| 素材原文件 | 你指定的素材库或原始文件夹 |
| 素材索引、缩略图、日志及导入前备份 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 物品封面图片缓存及预览工程 | 数据目录中的 `cover-previews` |
| 应用设置 | 数据目录中的 `settings.json` |
| 已记住的压缩包密码 | 本地数据库内，以密文存储 |
| 自定义分类与别名 | 数据目录中的 `categories.user.json` |

卸载只移除程序，素材库和应用数据保留在安装目录之外。
