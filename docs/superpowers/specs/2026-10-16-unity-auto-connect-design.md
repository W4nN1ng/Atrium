# Unity 自动连接与导入目标

用户已批准：打开 Unity 后自动准备连接，点击导入时自动选择当前工程；封面保持现状。开发、测试、PR 合并和本机安装版更新均在本轮完成。基线为最新 main `c606d0d`。

正常流程：打开受支持的 Unity 工程 → 自动识别并安装缺失连接插件 → 等待真实心跳 → 选素材 → 点击带工程名的导入按钮。打开工程本身不导入素材。工程从 VCC、扫描根或运行进程发现；关闭工程、内部封面预览工程不自动安装。

主进程统一管理连接与目标。当前模板支持 Unity 2022.3；安装前核对实际工程、路径与目录链接。仅首次缺失时安装，已有桥接复用，不强制覆盖手动修改。安装成功不等于连接就绪；就绪以 BridgeManager 的真实状态为准。失败保留明确原因和重试；不按每轮检测重装刷屏。

单个正在运行且受支持的用户工程自动成为目标；多个工程时，仅沿用用户明确选择的运行工程，否则提示选择一次。没有工程时提示打开 Unity。当前集合／匹配结果不参与导入去向。用户点导入便固定这次任务及其所有后续批次的工程 ID；新开、关闭或选择其他工程均不能把既有任务转投别处。

连接准备期间点击导入会等待原工程就绪，显示状态并允许取消等待。默认等待上限 180 秒；关闭、禁用、安装失败或退出应用会结束等待。连接之后的 Play／编译／导入忙碌继续使用现有串行队列与退避机制。保留当前冲突确认、备份和版本选择语义；本轮不顺带改确认偏好或合集选款。

正常流程取消安装询问。首次向导的连接步骤改为自动状态说明，无手动安装选择；高级页保留自动连接开关、重试及禁用／卸载。新设置独立于旧的 bridgeAutoInstall 和旧询问答案，旧默认关闭值不会阻止本次新默认行为；本轮以后用户主动禁用的工程不会被立即重装。

只用隔离应用目录、测试工程、素材副本验收；不拿真实素材库做测试。交付包含构建安装包、覆盖本机安装、注册表版本检查。封面源码、行为和桥接渲染实现不修改；旧功能需要回归。
