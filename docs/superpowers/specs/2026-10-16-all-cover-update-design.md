# 全库一键更新封面

用户已在查看交互方案后明确要求“开始做”。本文件落实该方案作为执行与验收记录，不新增审批步骤。

## 目标与用户操作

素材库工具栏始终提供“更新全部封面”，一次点击直接开始后台任务，不要求先多选卡片或再次确认。下拉选项提供当前筛选与所选素材。默认扫描全库可见素材类别（包括合集成员，排除附属及已删除资源），不受界面分页的 500 条上限影响。

已有持久关联沿用来源、物品、角度、背景；尚未关联优先从素材包发现候选，自动寻找 Unity 与已知依赖。完整且无截断、无警告的发现结果只有一个候选时，自动渲染保存；多个候选集中列入“待选图”，不按文件名猜选或盲取第一项。用户进入待选图页面后，点击候选图片即应用，关联持久保存；没有“生成”“再保存”的额外步骤。候选图按页生成，失败可重试。

默认保留商品图与手动上传图，不把原图当作空白。已有自动封面每次重新渲染，因此不再增加效果相同的“强制重拍”按钮，以减少用户需要理解的选项。不向用户改模工程导入素材，不改封面渲染核心或运行供应方脚本。

## 任务行为

主进程持有串行队列，UI 位于 App 层，切换页面或关闭任务面板不取消任务。显示完成、待选、失败、跳过数量及当前素材，不声称未经测量的剩余时间。提供明确停止、仅重试失败项、重新打开结果、撤销本次更新。单个失败不阻塞其他素材。

取消会终止当前尚未保存的生成，后续项停止；晚到结果不得保存。任务期间手动改图、删除素材或重新关联，均保留用户最新状态。候选归属、来源指纹及选择合法性在主进程校验；原包变化必须重新发现，不按旧图自动保存。

撤销恢复本次覆盖前的图片及完整关联，而非最早原图。每项只在当前封面仍由本任务生成时恢复，后续手动修改保留；撤销需要的图片加入缓存引用保护。任务历史有界，运行与待选候选图有界；不承诺退出应用后自动续跑。

## 验收

全库超过 500 条仍能遍历；唯一候选自动完成；多候选不自动写入且可一键选图；截断、警告、缺 shader、无模型保持原图；商品图/上传图保护；串行、停止、重试、页面切换、旧响应、原包变化、同卡并发及条件撤销均有回归。使用隔离数据库、合成素材、受控界面和独立 Unity 工程验证，不以用户头像或素材库作夹具。完整测试、类型检查、构建、独立审阅通过后正常 PR 合并，更新本机安装并核实注册表版本。无 GitHub Release 发布。
