**Atrium 是面向 VRChat 创作者的本地素材管理工具。** 在一个 Windows 桌面应用中完成素材收集、分类检索和 Unity 导入，便于管理模型、服装、贴图与插件。

**v0.9.3 新增两个小功能：项目列表可以拖出你自己的顺序并用 📌 钉住，导航里多了一个「导入历史」，告诉你素材导进 Unity 以后变成了什么名字。**

## 本次更新

### 项目列表：拖出你的顺序，📌 钉住常用的

- **按住任意位置就能拖**：把常用的工程拖到想放的位置，会出现一条插入提示线，松手立即生效，下次打开还是这个顺序。
- **📌 钉住**：点行尾的图钉，这个工程就永远排在列表最上面。以后新发现/新添加的工程不会挤到它前面。再点一次取消。
- **拖拽不会串台**：以前只有行首那个小手柄能拖，按着标题拖会被当成拖文件，屏幕上还会弹出「松手即自动分类」。现在整行都能拖，也不会再触发那个提示。

### 导入历史：素材导进 Unity 以后叫什么

- **回答一个问题**：素材在库里叫「糖果」，导进工程以后变成 `Assets/shinano Candy/` —— 到底哪个文件夹是哪个素材导进去的，以前只能靠猜。
- **名字取自包的落点，不是猜的**：导入前会读 `.unitypackage` 里每个文件的真实路径，取 `Assets/` 下的第一层文件夹名，Unity 就是照这些路径放进去的。
- **一次导入多个素材会逐条记**：每行写清「原名 → 工程里的名字」，下面一行小字是哪个工程、什么时候。一个包里有多个顶层文件夹时会一起列出来。
- **只留最近 100 条**：放满后自动丢掉最旧的。
- **清空**：右上角「清空」点一下会变成「确认清空？」，3 秒内再点一次才真的清空。只清这张列表，项目页里能撤销的导入记录一点都不受影响。
- 失败的、取消的导入不会记进来；纯代码包（里面没有可显示的名字）也不会留一行空白。

## 使用说明与已知限制

| 项目 | v0.9.3 的行为 |
| --- | --- |
| 工作范围 | Windows 11 已实测；Windows 10 尚未完成实机验证。 |
| Unity 版本 | 真机验证以 Unity 2022.3.22f1 为准；其他版本只验证了识别与匹配。 |
| 导入历史的来源 | 只从素材自带的包内路径取名，不联网查询 Booth 商品页。 |
| 导入历史的长度 | 固定保留最近 100 条，没有设置项可以改。 |
| 项目排序 | 固定的工程永远在最上面；拖拽只在「固定区」和「未固定区」内部换位，跨区请用 📌。搜索过滤时不能拖。 |
| 真 Unity 装包/启动/双击导入/旧式迁移 | 仍建议先在沙盒项目里确认；自动化与失败注入不能替代真机。 |
| 项目写入 | 会修改项目的 `Packages/` 和 `vpm-manifest.json`；应用会先预检并保留回滚副本，Unity 正在运行时会拒绝或等待。 |
| 网络 | 只有刷新仓库、下载包、检查更新会联网；关闭网络后仍可浏览已缓存的包。 |
| 数据目录 | 新安装默认 `%APPDATA%\Atrium`；已有安装保留原来的包数据目录。素材库在安装目录之外。 |
| 回退 | 可以用旧安装包覆盖回 v0.9.2；素材库与项目数据不受影响，项目列表顺序会依旧版本忽略。 |
| 代码签名 | 发布包未进行代码签名，Windows 可能显示 SmartScreen 提示。 |

## 数据位置

| 内容 | 默认位置 |
| --- | --- |
| 素材原文件 | 你指定的素材库或原始文件夹 |
| 素材索引、缩略图、日志、导入前备份，以及项目顺序/导入历史 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 项目与包数据库、包缓存、回滚区、项目备份 | 新安装默认 `C:\Users\你的用户名\AppData\Roaming\Atrium`；已有安装保留原目录 |
| 本地安装包投放目录 | 项目与包数据目录下的 `updates` |
| 已记住的压缩包密码 | 本地数据库中，以密文存储 |

卸载只移除程序，素材库和应用数据保留在安装目录之外。
