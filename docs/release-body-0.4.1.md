# Atrium 0.4.1

给 VRChat 改模玩家用的素材管家。**Windows 桌面程序，完全离线。**

你大概有过这种时候：想找个眼熟的猫耳，只记得是 Booth 上买的、好像叫 "Shinano" 什么的，
解压出来又不知道塞在哪个文件夹里了。包套包、日文文件名、同一个模型的三个体型、五六个版本 ——
三年下来就是一团 20 多 GB 的乱麻。

**这个程序做的事很简单：你把包丢进去，它替你拆开、看清楚里面是什么、归到该在的地方；
之后你打开哪个 Unity 工程，它就自动翻到那个模型的那一格，勾一下就能装进去。**

这一版不改功能方向，专修「界面上有那个开关、点了却没用」和「第一次用就被绕晕」这两类毛病 ——
十二条，全部来自真机使用里撞出来的问题。

---

## 这次修好了什么

**输入框里按 `Ctrl+Z`，不再把你刚入库的素材撤回。** 以前你在搜索框里打错字想撤销，
它以为你要撤销的是「刚刚那笔入库」，一下把素材退回收件箱了。现在：光标在文字里，
撤销就只管文字；库的撤回还是老样子，在别处按 `Ctrl+Z` 就行。

**直接丢一个 `.unitypackage` 进去，分类变准了。** 以前这种包只有装在 zip 里才会翻内容，
你直接把包丢进去时它只看文件名猜 —— 猜错了就进「待复核」。现在两种放法一样对待：
它会打开包看里面的 `Assets` 路径，知道这是模型、贴图还是插件工具再定。
（包的原件一点没动，还是能直接导入 Unity。）

**设置里的开关是真的开关了。** 以前有两条「看着能改、改了没用」：
- **保留原始压缩包**：关掉之后，归档模式下它确实会把解压出来的东西收好 —— 现在原包会被
  挪进可撤销的暂存区，你按 `Ctrl+Z` 能整批退回去。没解压成功、或者解压出来是空的，原包留在原地不动。
- **导入前确认**：开着时哪怕没有同名冲突也会先让你看一眼；关掉时没冲突就直接导入，不再多问一句。
  **有冲突时永远会问你** —— 这条不受开关影响。

**「拿不准就问」那根线真的跟着你走了。** 设置里那个把握程度以前是装饰，
实际判断一直卡在固定值上。现在你调到哪儿就按哪儿判；
一套合集聚合时既看里面每一件的把握，也看这一套加总的把握。

**快捷键能改回去了。** 以前把 `A` 改成 `B` 再改回 `A`，注册表里就乱了，
`A` 从此按不出来。现在它会记住当前到底注册的是哪个键，改失败、或者被别的程序占了，
自动退回原来那个键，不会把你锁死。

**第一次配置时点「稍后」不会被永久拉黑。** 那个小助手（往 Unity 工程的
`Packages` 文件夹放一小段传话脚本）以前你点了「暂不」，它就记成「永远不要问」，
之后不管你怎么打开那个工程它都不提了。现在「稍后」只是这一次不问，
下次打开同一个工程它还会问。你之前真的点过「暂不」的那些工程，它不会擅自改你的记录 ——
随时能从「当前工程」那一页手动连上。

**发现好几个 Unity 工程时，一屏挑完。** 以前是连着弹几个窗，一个一个问「要不要装」，
手快点成串之后就记不清答应了什么。现在**一个窗口列出这次发现的全部工程**，
只给勾上的装，没勾的这次跳过、下次还会问。

**不会让你把 Unity 工程指成素材库。** 以前向导里真能选到一个工程目录，
选完它就开始往工程里塞解压出来的素材。现在向导和设置里两条改库的路都会先看清楚：
是 Unity 工程、在工程里面、是盘符根目录（比如整个 `D:\`）、是系统目录 —— 一律拒绝，
并用一句人话告诉你为什么。

**空白页不再让你对着发呆。** 收件箱空着的时候以前只有一句「还没有素材」，
现在多了一颗「添加素材」按钮和一段「接下来会发生什么」的说明。
第一次设置的向导也修了：文案写「三步」实际是四步，现在中・英・日三种语言都写四步。

**看不懂的词全换成大白话。** 「分类置信度阈值」「工作进程」「回退暂存区」这类内部说法，
在界面上改成了「拿不准就问」「后台整理」「先收到一边，能撤回」。
出错了给的话也不再是一串英文路径，改成一句「这个文件为什么没收下、你能怎么办」。

## 这版能做什么

**丢进去就行**

- 四种放法随你挑：拖进窗口、文件夹里右键「发送到 Atrium」、指定一个下载文件夹让它自动收、或者叫它去看某个目录
- `.zip` `.rar` `.7z` `.unitypackage` 都吃，包中包也能拆开；日文包名不乱码
- 带密码的包会问你要。勾一下「记住这个密码」，下次再撞见同一个包它自己就试出来，不用你翻聊天记录
- 一个压缩包里装了 17 件东西时，可以只挑其中几件，不用整包拆开
- 松手了却什么都没进来时，它一定说一句为什么（比如从浏览器里拖图、从压缩窗口里拖一行，都拿不到本地位置）

**它真的看得懂**

- 不是只看文件名猜。它会翻包里的东西 —— 模型、材质、贴图、音效、还是插件工具 ——
  再告诉你它判断这是什么、有多大把握、**为什么这么判断**
- 拿不准的不替你拍板：要么停在收件箱等你点确认，要么先入库再挂进「待复核」，
  你瞄一眼点「标记已复核」就算归队
- 你手动改过的分类它会记住，下次同类东西不再问第二遍
- 一个包里真是 17 件一套的商品时是一张卡（写着「含 17 项」）；名字说了是"多少件"的那种筐，
  里面每件各自成卡
- 同一个模型的三个体型、五个版本会并成一张卡，上面写「适配模型 ×3 · 版本 ×5」，点开才是一层层清单
- 搜索拼音、日文、英文互相能搜到同一个东西：打 `shinano`、`シナノ`、`信乃` 都算。
  分类的口语叫法也认（打 `yifu` 找到「服装」），你自己加的别名不用重启就生效

**管得住**

- 自动给每个素材生成封面图，卡片视图 / 列表视图随你切，还能按模型分「格子」（集合）
- **改分类会真的把文件搬到新目录**：搬之前先给你看单子 —— 几个文件、搬到哪儿、会不会盖掉谁；搬完能整批撤回
- 库体检：找出重复的素材、封面长得很像的、没登记的文件、记录了但文件没了的、超大的
- 「设置 → 维护」里还有几样收拾旧账的：重新整理合集、拆开跨目录的归并组 ——
  都先给你看单子再动手，都不搬文件，都能整批撤回
- 升级后第一次打开，它自己就把「同一件衣服散成好几张卡」这类旧账并好了，并在顶部说一句动了什么
- 删除一律进**回收站**，不会直接抹掉；大部分操作 `Ctrl+Z` 能撤回
- 已经有一个乱了几年的库？第一步指给它，它会问「**接管这个库**（只登记，一个文件都不搬不改名）/ 当成空库」，
  选接管还会顺手关掉自动归档，之后每张卡都要你点确认才动盘

**跟 Unity 配合**

- 你打开某个 Unity 工程，Atrium 自己翻到那个模型的那一格（同一个工程五分钟内不会反复跳，拿不准就只更新顶部提示不跳）
- 勾几个资源点导入，一个一个送进去、报进度；装之前先检查有没有同名文件会被盖掉，会盖掉的先备份
- Unity 正在播放模式时不报错，排队等它空闲了自己接着跑完
- 装错了点「退回」，资源真的从工程里删回去，并告诉你新建了几个、覆盖了几个
- 每张素材卡的详情页能反查「这东西被装进过哪些工程」
- 合集里能一层层滚到底，每行右边能直接导，顶上那颗「整包导入 Unity」会把能导的包全部预先勾上让你数一遍再确认
- 常驻右下角托盘；`Ctrl+Alt+A` 在鼠标位置弹一个小投放窗，拖文件进去就行
- 界面三种语言：简体中文 / English / 日本語

**完全离线**：不联网、不上传任何东西。

## 第一次怎么用

1. 装好打开 → 它会问你四件事：**素材放哪儿** → **素材从哪儿来** → **要不要给 Unity 工程装个小助手** → **要不要开机常驻右下角**。
   只有第一步不能跳过；中途点「稍后配置」不会被拦，但左边栏会一直留着「库还没配好，点这里继续设置」
2. 已经有素材库就选**接管**；新库就指个空文件夹。**别把 Unity 工程指进来**，它会拒绝
3. 把东西丢进去（或者右键「发送到 Atrium」）。等它分析完，在「待复核」里过一眼，点「全部入库」，
   看过的卡点「标记已复核」就归队
4. 装过小助手的工程打开 Unity → 顶部会出现「正在编辑 xxx」的横幅，点它就切到对应的格子

那个「小助手」只是往工程的 `Packages` 文件夹里放一小段传话脚本，**不碰你的 `Assets`、不改你的场景**；
第一次发现新工程时会先问你一句，你说不要它就不动。

## 现在还不会做的事

- **没有软件签名**，第一次运行要手动放行（原因见上面）
- **它自己的数据目录搬不了盘**，固定在 `C:\Users\你的用户名\AppData\Roaming\A`（素材库本体想放哪儿都行）
- **这次改的这几条里，有两条我只能靠模拟验证**：真实 Unity 导入的成败、
  以及快捷键被别的程序抢走时到底是什么表现 —— 这两件得在你机器上真用才算数。
  跨盘拷贝失败时的退回也是模拟出来的，不是真拔了硬盘测的
- **「保留原包」那个开关关掉后不会立刻腾空地方**：原包先挪到可撤销的暂存区，
  等你确认这单不撤回了，空间才是真省下来了
- **索引模式只登记，文件保持在你原来放的位置**，不搬家
- **从资源管理器真实拖文件夹这一条我没法自动测**（脚本发起不了一次真实的拖拽）。
  窗口里能测的都测过了：拖进来一定会有高亮、拿不到文件位置一定会说话。
  万一你真撞上"拖进去啥也没发生"，用「收件箱 → 选择文件…」或右键「发送到 Atrium」，然后告诉我
- **一次导入分了好几批时，界面上只能退回最后那一批**，前面的批次得从「设置 → 维护」的账本里想办法
- **退回之后工程里会留下几个空文件夹**（东西删干净了，空目录还在），不影响使用，看着烦
- **它答不了「我这个工程现在装了哪些东西」**，只能答「Atrium 帮你导过哪几次」
- **重复素材只列出来给你看，不自动删** —— 删哪一份得你决定
- **封面相似只比封面图**，不比对其它图片
- **中文名字想用日语读音搜不支持**（打 `sokubaku` 搜不到「束縛」）—— 这是想清楚之后的取舍，不是漏做
- **不会帮你问 AI**，「拿不准时问一下模型」这个功能完全没做
- 包里的日文文件名**少数几种编码还是会乱码**（换过码页的那一类），已经找到原因，下一轮修
- 只在 **Windows 11 + Unity 2022.3.22f1** 上真机测过；Windows 10 应该能跑但我没机器试

## 你的东西都在哪儿

| 内容 | 位置 |
|---|---|
| 你的素材本体 | 你自己指定的文件夹，想搬盘随时搬 |
| 它的记账、封面图、日志、备份 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 设置（库在哪儿、各种开关） | 上面那个文件夹里的 `settings.json` |
| 你记住的压缩包密码 | 同一个数据文件里，用你的 Windows 账户加密，界面上永远不会显示密码本身 |
| 你自己加的口语叫法 | 同一个文件夹里的 `categories.user.json`，升级不会丢 |

卸载只删程序本身，上面这些全在安装目录之外。
