**Atrium 是面向 VRChat 创作者的本地素材管理工具。** 在一个 Windows 桌面应用中完成素材收集、分类检索和 Unity 导入，便于管理模型、服装、贴图与插件。

**v0.9.0 新增项目与包管理，导入改为双击素材卡，并补上崩溃恢复、备份回退和一批稳定性改进。**

## 本次更新

### 项目与包管理

- **在应用里管理 Unity 项目：** 添加已有项目、查看项目和包列表、创建新项目、启动 Unity，并把打开的项目自动设为素材导入目标。双击素材即可导入当前项目。
- **装包不用再开别的工具：** 浏览包仓库，查看版本与依赖，安装、升级、降级、重装或移除包。依赖冲突、缺少依赖和受保护包会先给出说明，不会直接改项目。
- **仓库与本地包：** 支持官方与自定义包仓库、添加或排序仓库、私有仓库请求头；也支持从本地文件夹安装包，以及只读导入 VCC 的项目和模板。
- **模板与工程维护：** 内置和自定义项目模板可新建、编辑、复制和收藏；支持备份项目、从备份新建、复制项目、更换 Unity 版本，以及旧式资源迁移。
- **操作有记录、能撤销、能恢复：** 每次装包都有记录，可撤销最近一次安全操作；中途失败会尽量自动回滚，无法判断时会停下来并说明原因，修好现场后可以重试恢复。
- **项目写入有保护：** Unity 正在运行、素材正在导入、备份或迁移正在进行时，装包会等待或拒绝，避免两边同时改文件。

### 导入手势更简单

- **双击素材卡：** 直接把素材导入当前 Unity 项目，不再需要先点常驻的「导入到 Unity」按钮。
- **长按合集卡 1 秒：** 打开合集，避免和双击导入抢同一个手势。
- **多项目时先选一次：** 同时打开多个项目时，导入前会让你确认目标；选过一次后继续沿用。

### 更稳、更快

- **崩溃恢复：** 装包过程中退出或断电，下次启动会按操作记录回滚或补完；不会把半完成状态说成成功。
- **锁与并发：** 同一项目同时只允许一个写入操作，两个项目可以并行；失败、取消或恢复后不会留下一直占用的锁。
- **安全和备份：** 旧包与旧资源先进入回滚区，不永久删除；ZIP 解压会拒绝路径穿越、符号链接和异常压缩包；导出的诊断不包含密码或请求头。
- **性能与兼容：** 大目录查询、分页和依赖解析做了优化；增加中文、空格、长路径和多个 Unity 版本的识别验证。

### 应用内更新

- **设置里检查更新：** 手动检查新版本，下载并核对发布页给出的校验值后再安装；发布说明里没有校验值时不提供一键安装。
- **本地安装包：** 自己构建的安装包放进应用数据目录的 `updates` 文件夹后，更新面板会直接列出来并打开安装程序，不用去资源管理器翻文件。

## 主要功能

### 素材收集与整理

- 支持拖放、资源管理器「发送到 Atrium」、监视文件夹和目录扫描。
- 支持 ZIP、RAR、7z、Unity Package 及嵌套压缩包；可选择处理部分成员。
- 支持加密压缩包，在用户选择记住密码后加密保存。
- 结合文件名、包内路径和内容特征给出分类建议，展示判断依据。
- 识别合集、适配模型与版本，将同一商品的多个变体归并展示。
- 提供封面、集合、重复检查和库维护入口；文件删除优先使用系统回收站，多种操作可撤销。

### 检索与素材库管理

- 支持拼音、假名、罗马字、模型别名及自定义别名搜索。
- 提供卡片与列表视图、素材封面和物品封面编辑。
- 归档模式下，分类调整前可预览文件移动与覆盖情况，完成后支持整批撤回。
- 支持从素材包或已导入的 Unity 项目生成物品封面；没有 Unity 时仍可选择本地图片。

### Unity 项目与包

- **项目：** 添加、扫描和创建 Unity 项目，启动编辑器，查看项目里的包和版本。
- **包：** 浏览仓库、安装/升级/降级/重装/移除，解析依赖，处理冲突和受保护包。
- **模板：** 使用内置模板或自己的模板创建项目；模板可带依赖和附件。
- **维护：** 备份项目、从备份新建、复制项目、更换 Unity 版本、迁移旧式资源。
- **记录：** 查看装包历史、撤销安全操作、重试失败恢复；所有写入先预检，Unity 正在使用项目时会拒绝。

## 快速开始

1. **选择素材库。** 新建素材库可选择独立文件夹；已有素材库可选择「接管这个库」，先登记文件，不移动或重命名原有内容。
2. **设置素材来源。** 可指定需要监视的下载文件夹，也可随时手动添加素材。
3. **连接 Unity 项目。** 打开受支持的 Unity 项目后，Atrium 会准备连接；缺少桥接时会安装到项目的 `Packages` 文件夹，不修改 `Assets` 或场景。
4. **按需装包。** 在「项目与包」里添加包仓库，浏览并安装需要的包；不确定时先看依赖和冲突说明。装包前请保存项目并关闭 Unity。
5. **导入素材。** 双击素材卡导入当前项目；同时打开多个项目时先选一次目标。

## 使用说明与已知限制

| 项目 | v0.9.0 的行为 |
| --- | --- |
| 本地处理 | 素材分析与分类无需联网，素材不上传至云端。 |
| 项目与包管理 | 会改 Unity 项目的 `Packages/` 和 `vpm-manifest.json`；应用会先预检并保留回滚副本。Unity 正在运行或素材正在导入时可能拒绝或等待。 |
| 网络 | 只有刷新包仓库、下载包、检查更新和打开外部链接会联网；关闭网络后这些功能不可用。 |
| Ubuntu / macOS | 不支持，当前只提供 Windows 版本。 |
| Windows 版本 | 在 Windows 11 上验证；Windows 10 尚未完成实机验证。 |
| Unity 版本 | 真机验证以 Unity 2022.3.22f1 为准；2019/2021/6000 只验证了版本识别与匹配，没有用它们实际装包。 |
| 真 Unity 装包/启动/双击导入/旧式迁移 | 自动化与失败注入已覆盖，但仍建议先在沙盒项目里确认；发布说明不把未实测的组合写成已验证。 |
| 图片与封面 | 物品封面需要本机可用的 Unity 2022.3、许可证和 GPU；URP/HDRP、粒子、动画和自动下载依赖尚未支持。 |
| 长路径 | 超过 260 个字符的文件不会进入备份，会显示「路径太长」警告；这是刻意保留的策略线。 |
| 数据目录 | 新安装默认使用 `C:\Users\你的用户名\AppData\Roaming\Atrium`；已有安装会保留原来的包数据目录，本次不提供界面迁移。素材库可以在其他磁盘。 |
| 缓存与回滚区 | 包缓存、回滚区和项目备份会跟随包数据目录，可能占用数 GB 空间；可在设置里查看用量。 |
| 删除与回退 | 删除项目会整个文件夹进回收站；盘上没有回收站时退化为移到数据目录的 `trash`。回退到旧版本不会自动还原 Unity 项目文件。 |
| 代码签名 | 发布包未进行代码签名，Windows 可能显示 SmartScreen 提示。 |
| 项目与包数据 | 项目与包管理使用独立数据库；核心素材库的表结构保持不变。 |

**兼容性：** 已验证环境为 Windows 11 + Unity 2022.3.22f1；Windows 10、其他 Unity 版本和 URP/HDRP 仍需按你的实际项目确认。

**验证范围：** 已完成自动化测试、构建检查、安装版启动和隔离环境中的界面流程验证；真实 Unity 的装包、启动、双击导入和旧式迁移仍以沙盒项目实测为准。详情见 [验证记录](https://github.com/W4nN1ng/Atrium/blob/main/docs/VERIFY-UNVERIFIED.md) 和 [开发文档](https://github.com/W4nN1ng/Atrium/blob/main/docs/DEVELOPMENT.md)。

## 数据位置

| 内容 | 默认位置 |
| --- | --- |
| 素材原文件 | 你指定的素材库或原始文件夹 |
| 素材索引、缩略图、日志及导入前备份 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 项目与包数据库、包缓存、回滚区、项目备份 | `C:\Users\你的用户名\AppData\Roaming\Atrium`（已有安装保留原目录） |
| 应用设置 | 对应的数据目录中的 `settings.json` |
| 本地安装包投放目录 | 项目与包数据目录下的 `updates` |
| 已记住的压缩包密码 | 本地数据库中，以密文存储 |

卸载只移除程序，素材库和应用数据保留在安装目录之外。
