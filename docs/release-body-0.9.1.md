**Atrium 是面向 VRChat 创作者的本地素材管理工具。** 在一个 Windows 桌面应用中完成素材收集、分类检索和 Unity 导入，便于管理模型、服装、贴图与插件。

**v0.9.1 修复项目包列表的显示与添加问题，并兼容 ALCOM/VCC 生成的工程文件。**

## 本次更新

### 项目包列表更清楚

- **显示包名，不再只显示内部 ID：** 例如显示 `VRChat SDK - Avatars`、`Gesture Manager`、`lilToon`，下面再用小字标出 `com.vrchat.avatars`。
- **来源显示仓库名：** Official、Curated、bd_、lilxyzw 等会直接写在包名下方；只在工程里、仓库里没有的包显示“工程内包”，不再统一写成 `embedded`。
- **最新版本按你的偏好显示：** 没有开启预发布时，3.10.6-beta.2 不会再被当成最新版；已安装的 3.10.5 会显示为正常状态，不再出现误导性的“有更新”。
- **已安装状态更准确：** 作为依赖装进工程的包（例如 VRChat SDK - Base）也会显示为已安装，不再全是“未列出”。

### 可以直接从仓库添加包

- **“添加软件包”入口：** 在项目的“管理软件包”里搜索已启用的仓库，选择包和版本，再走原来的变更预览。
- **先预览再写入：** 会先显示会新增哪些包、会带入哪些依赖、要下载多少；确认并关闭 Unity 后才真正修改工程。
- **已安装的包也能选版本：** 选更高版本是升级，选更低版本是降级，选当前版本是重装。

### 首次导入后封面立刻出现

- **不再等重启：** 一次拖进很多素材时，封面以前常常只有一两张出来，其余要关掉应用重开才有。现在入库那一刻没生成出来的封面会自动再补两次（约 2 秒、5 秒），图片一到位就刷新，不用重启。
- **不会再把“暂时没读到”记成“这包没图”：** 刚解压完立刻拖进来时，源文件夹可能还没落稳。以前这种情况会被永久标成“无封面”，之后再也不补；现在只有确实看过目录、里面真的没有可用图片时才会这么记。

### 工程扫描不再误报“结果不完整”

- **普通工程不再被旧资源扫描打扰：** 提高了 Assets 旧资源扫描的条目/层级上限；像深层 Animation/Controller 目录不会再触发“工程扫描达到上限”。
- **不影响包管理：** 这条提示原本只影响“旧式资源迁移”的建议列表，和已安装包、装包/升级/卸载无关。

### 兼容 ALCOM/VCC 工程

- **读取 ALCOM/VCC 的工程包清单：** 支持新版 `vpm-manifest.json` 中带版本对象的依赖写法；已有项目不会再因此显示成“全部未列出”。
- **写回不降级格式：** 装包、升级、卸载后保持原来的清单格式，不会把 ALCOM/VCC 生成的依赖对象改成旧格式。
- **依赖包状态：** 锁定在工程里的传递依赖会按已安装处理，装包计划不会误把它们当成“未列出”的包。

## 使用说明与已知限制

| 项目 | v0.9.1 的行为 |
| --- | --- |
| 工作范围 | Windows 11 已实测；Windows 10 尚未完成实机验证。 |
| Unity 版本 | 真机验证以 Unity 2022.3.22f1 为准；其他版本只验证了识别与匹配。 |
| 真 Unity 装包/启动/双击导入/旧式迁移 | 仍建议先在沙盒项目里确认；自动化与失败注入不能替代真机。 |
| 项目写入 | 会修改项目的 `Packages/` 和 `vpm-manifest.json`；应用会先预检并保留回滚副本，Unity 正在运行时会拒绝或等待。 |
| 网络 | 只有刷新仓库、下载包、检查更新会联网；关闭网络后仍可浏览已缓存的包。 |
| 数据目录 | 新安装默认 `%APPDATA%\Atrium`；已有安装保留原来的包数据目录。素材库在安装目录之外。 |
| 回退 | 可以用旧安装包覆盖回 v0.9.0；素材库不受影响，项目与包数据会保留。 |
| 代码签名 | 发布包未进行代码签名，Windows 可能显示 SmartScreen 提示。 |

## 数据位置

| 内容 | 默认位置 |
| --- | --- |
| 素材原文件 | 你指定的素材库或原始文件夹 |
| 素材索引、缩略图、日志及导入前备份 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 项目与包数据库、包缓存、回滚区、项目备份 | 新安装默认 `C:\Users\你的用户名\AppData\Roaming\Atrium`；已有安装保留原目录 |
| 本地安装包投放目录 | 项目与包数据目录下的 `updates` |
| 已记住的压缩包密码 | 本地数据库中，以密文存储 |

卸载只移除程序，素材库和应用数据保留在安装目录之外。
