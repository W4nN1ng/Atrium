- 完整测试：1552 通过、31 按条件跳过，0 失败（127 个测试文件中 117 通过、10 整组跳过）。

- 隔离 Electron 33.4.11 中运行编译后的主进程、预加载和 React 页面：四步向导、Unity 素材库拒绝、无效阈值拒绝、三工程批量连接、仅安装勾选工程、未选工程临时跳过均通过。
- 代码复核发现的合集阈值、跨盘恢复、路径规范化和错误翻译问题已补回归并修正。
- 本机 C 盘剩余空间不足，性能测试曾报数据库磁盘已满；将本次测试 TEMP/TMP 指向 E 盘后，全套测试包括五万条素材性能测试通过。没有调整性能断言。

## 实际使用与限制

测试不会连接或修改真实 Unity 工程。真实 Unity 导入结果、操作系统热键抢占和真实双盘硬件行为仍需使用时验证；跨盘复制的失败回退已在临时文件中模拟测试。

“关闭保留原包”先把原包移到可撤销暂存区，因此不会立即减少整台电脑的占用空间。索引模式只登记，文件保持原位置。

历史版本点过“暂不”而留下的永久拒绝记录不会被擅自删除。这些工程仍可从“当前工程”页手动连接。

拉取修复分支后，在项目目录运行 `npm run dev`。如果刚运行过测试，该命令会先切回 Electron 所需的 SQLite 模块。
