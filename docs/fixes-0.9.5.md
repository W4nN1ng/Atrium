# 0.9.5：导入历史与项目排序修复

继续处理 0.9.3 审计中剩余的第 4–6 项。第 1–3 项已在 0.9.4（PR #47）修复。

## 修复结果

4. **导入历史实时更新**：页面保持打开时，单包导入成功及批量导入每个成员成功后都会刷新。失败或取消不追加名字记录。清空后通知其他窗口，并忽略较早发出、较晚返回的读取，避免旧列表重新出现。清空仍只删除名字列表，不修改撤销用的 `import_log`。
5. **保留带点的文件夹名**：`Assets/com.example` 与其子文件只显示一个 `com.example`，不再出现 `com、com.example`。解析 Unity 的 `folderAsset: yes` 元数据，空目录也保留原名；根目录中的 `Candy.mat` 仍显示 `Candy`。支持一次性迭代器、反斜杠和条目先后顺序变化。已有历史是导入当时的快照，本次不重写旧记录。
6. **排序与固定设置可靠保存**：读取失败时显示错误和刷新入口，恢复读取前禁止修改；保存失败时恢复上一次已确认的布局，并在列表上显示错误。保存期间禁用固定与拖拽，同时在事件入口阻止并行写入。成功后的顺序和固定状态在切换页面、重启应用后保留。
