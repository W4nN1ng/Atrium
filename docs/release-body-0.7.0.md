**Atrium 是面向 VRChat 创作者的本地素材管理工具。** 在一个 Windows 桌面应用中完成素材收集、分类检索和 Unity 导入，便于管理模型、服装、贴图与插件。

**v0.7.0 新增 Unity 自动连接与一键更新全部封面，移除「待复核」，并修复封面显示成同一张的问题。**

## 本次更新

### Unity 自动连接

- **打开工程即连接：** 打开受支持的 Unity 工程后自动准备连接，导入前不用再去「当前工程」里手动点一遍。连接就绪后才开始执行你发起的导入。
- **首次自动安装桥接：** 工程里还没有 Atrium 桥接时自动安装，装到工程的 `Packages` 文件夹，不修改 `Assets` 或场景。
- **多工程时让你选：** 同时开着多个 Unity 工程时，导入前会问这次用哪一个；导入按钮上直接写着工程名。选定后后续批次继续使用它。
- **状态如实显示：** Unity 未打开、暂不支持此版本、正在连接、已连接、连接失败、等待超时各有对应提示，失败时说明原因并可「重试连接」。
- **可关闭：** 「设置 → Unity」可停用自动连接；首启向导里也增加了这一步，可跳过，以后需要时再打开。

### 一键更新全部封面

- **按范围更新：** 「更新全部封面」可选全部素材、当前筛选结果或所选素材，依次生成封面。
- **只补该补的：** 商品自带图片和手动上传的封面会保留，不会被自动生成的图盖掉；已有自动封面则重新拍摄。
- **遇到多个物品时交给你选：** 一个素材里找到多件可拍物品时不停下来猜，而是列出来让你选图。
- **后台运行：** 关闭面板后继续执行，可从顶部重新打开查看进度，显示完成、待选图、失败和跳过各自的数量。
- **可停止、重试与撤销：** 随时停止（已完成的封面保留）、只重试失败项，或整次撤销回到更新前的封面。

### 移除「待复核」

- 侧栏的「待复核」入口、单卡上的「标记已复核」、合集里的批量标记和卡片上的低置信度角标一并移除。
- 判断不明确的素材照常入库，不再需要额外确认一次；分类结果仍可随时在素材详情里修改。
- 升级时自动清理数据库中对应的记录字段，素材记录、分类和封面都不受影响。

### 封面相关修复

- **封面显示成同一张：** 入库时同一批里的每个素材误用了整批共用的文件指纹，导致它们的封面全部落到同一张缩略图上。现已修复，升级后会自动纠正受影响的记录，并为每个素材重新生成各自的封面。
- **「选择本地图片」打开的位置：** 文件对话框不再停在上一个素材的目录，而是直接打开当前素材所在的文件夹。找一个游戏多件道具的图片时不用再手动翻回去。

## 主要功能

### 素材收集与分类

- 支持拖放、资源管理器「发送到 Atrium」、监视文件夹和目录扫描。
- 支持 ZIP、RAR、7z、Unity Package 及嵌套压缩包；可选择处理部分成员。
- 支持加密压缩包，在用户选择记住密码后加密保存。
- 结合文件名、包内路径和内容特征给出分类建议，展示判断依据。
- 识别合集、适配模型与版本，将同一商品的多个变体归并展示。

**素材分析与分类在本地完成。** 判断不明确的素材照常入库，分类结果可随时修改；当前版本不调用在线 AI 模型，设置中的模型相关选项尚未参与分类流程。

### 检索与素材库管理

- 支持拼音、假名、罗马字、模型别名及自定义别名搜索。
- 提供卡片与列表视图、素材封面编辑和集合管理。
- 支持一键更新全部封面，以及整次撤销。
- 归档模式下，分类调整前可预览文件移动与覆盖情况，完成后支持整批撤回。
- 库检查可列出重复素材、相似封面、未登记文件和失效记录。
- 「设置 → 维护」提供索引重建、归并检查及手动数据库备份。
- 素材库中的文件删除使用系统回收站，多种库操作支持 `Ctrl+Z` 撤销。

### Unity 集成

- 打开受支持的 Unity 工程时自动连接，首次缺少桥接时自动安装。
- 发现本地 Unity 工程，并根据与集合的匹配结果切换视图；匹配不明确时显示提示。
- 导入前检查资源冲突，支持备份被覆盖的文件；批量导入显示进度。
- Unity 处于播放模式或忙碌状态时，导入请求排队等待。
- 「当前工程 → 导入历史」可按批次查看并撤回经由 Atrium 执行的导入。
- 素材详情可查看经由 Atrium 导入的工程记录，最近一次批次提供快捷撤回入口。
- 支持从素材包或已导入的 Unity 工程生成物品封面。
- 支持托盘常驻和 `Ctrl+Alt+A` 素材投放窗口。
- 界面支持简体中文、English 和日本語。

## 快速开始

1. **选择素材库。** 新建素材库可选择独立文件夹；已有素材库可选择「接管这个库」，先登记文件，不移动或重命名原有内容，并关闭高置信度自动归档。
2. **设置素材来源。** 可指定需要监视的下载文件夹，也可随时手动添加素材。
3. **连接 Unity 工程。** 勾选需要连接的工程；也可以只打开 Unity，Atrium 会自己连上。桥接安装到 `Packages/com.avca.bridge`，安装过程不修改 `Assets` 或场景。
4. **选择启动偏好。** 按需要决定是否开机启动，默认关闭。

配置素材库后，将素材拖入收件箱，检查分类建议并确认入库。导入 Unity 时选好素材和目标工程再确认；连接会在导入前自动完成。衣柜、道具、插件这类没有预览图的素材，可在素材详情点击「编辑封面」生成图片，或用「更新全部封面」一次补齐。向导可稍后继续，其余设置可在设置页调整。

## 使用说明与已知限制

| 项目 | v0.7.0 的行为 |
| --- | --- |
| 本地处理 | 素材分析与分类无需联网，素材不上传至云端。 |
| Unity 自动连接 | 需要本机可用的 Unity 2022.3 与可写入的工程目录。工程在播放模式或正在编译时会等待，等待超时后提示重试。不支持该版本时会说明原因，需要手动升级工程。 |
| 自动连接的范围 | 只对「当前工程」里已加入的工程自动准备连接，不会自己去打开 Unity，也不会往未加入的工程里安装桥接。 |
| 更新全部封面 | 需要本机可用的 Unity 2022.3、许可证和 GPU；任务串行执行，一件失败不影响其余。商品图和手动上传的封面会跳过，不会覆盖。 |
| 物品封面环境 | 已验证 Unity 2022.3.22f1 与 Built-in 渲染管线。支持 MeshRenderer 和 SkinnedMeshRenderer；隐藏的子物体不参与拍摄，LOD 使用第一层网格。不运行道具脚本、Animator、MA/NDMF 构建或 VRChat 交互逻辑，因此封面不是游戏内效果验证。URP/HDRP、粒子、动画和自动下载依赖尚未支持。 |
| 素材包预览格式 | 素材包模式支持 ZIP 与 `.unitypackage` 的静态 Built-in 资源；RAR、7z、加密和嵌套压缩包需要先整理为受支持的包，或改用工程模式。 |
| 素材包预览上限 | 原包上限 512 MiB、解压资源 2 GiB，最多 32 个包、20,000 个条目和 10,000 个资源标识，读取截止 45 秒。 |
| 预览缓存 | 应用保留至多三个已准备的预览工程；未清理的缓存在后续预览前清理。生成图片为预览用途，最长边 320 像素。 |
| 同一批素材的重复判断 | 同一批里入库的多个素材不再共用一个文件指纹，因此不会互相误判为重复；也意味着这批素材暂时不参与「重复素材」检测，重新单独入库后会恢复。 |
| 导入历史撤回 | 依赖对应工程和桥接在线，只处理导入记录中的资源，不保证恢复后续的手动修改。撤回后可能保留空目录。 |
| 数据库备份范围 | 副本不包含素材原文件、缩略图、Unity 工程和导入前文件备份；本轮没有增加从备份恢复数据库的界面。 |
| 索引模式 | 只登记素材，文件保留原有位置。 |
| 工程记录 | 只记录经由 Atrium 执行的导入，不提供 Unity 工程全部资源的清单。 |
| 重复与相似检测 | 重复素材需手动选择处理，相似检测仅比较封面图。 |
| 搜索范围 | 支持已知及自定义别名，不提供任意中文名称的日语读音转换。 |
| 文件名编码 | 无编码标记的文件名可能存在识别歧义；已增加 EUC-JP 候选，特别短的纯汉字名称仍需人工核对。 |
| 数据目录 | 应用数据默认位于 `C:\Users\你的用户名\AppData\Roaming\A`，暂不提供界面迁移；素材库可选择其他磁盘。 |
| 密码保存 | 密文保存于本地数据库，解密依赖当前 Windows 账户与设备，换机后可能无法解密；数据库备份中的密码密文同样如此。 |

拖放内容缺少可读取的本地路径时，可先保存或解压到本地，再使用「收件箱 → 选择文件…」或资源管理器「发送到 Atrium」。

**兼容性：** 已验证环境为 Windows 11 + Unity 2022.3.22f1；Windows 10 尚未完成实机验证。

**验证范围：** 已完成自动化测试、构建检查及隔离环境中的界面与后台流程验证，物品封面另有独立 Unity 工程的实际渲染验收。Unity 自动连接的多工程选择、真实头像的 SDK 构建与上传、VRChat 游戏内效果、系统热键冲突、资源管理器拖放和跨盘故障场景仍需实机验证。详情见 [封面使用说明](https://github.com/W4nN1ng/Atrium/blob/main/docs/UNITY-COVERS.md)、[导入历史与备份说明](https://github.com/W4nN1ng/Atrium/blob/main/docs/FIXES-2026-10-11-IMPORT-RECOVERY.md) 和 [验证记录](https://github.com/W4nN1ng/Atrium/blob/main/docs/VERIFY-UNVERIFIED.md)。

## 数据位置

| 内容 | 默认位置 |
| --- | --- |
| 素材原文件 | 你指定的素材库或原始文件夹 |
| 素材索引、缩略图、日志及导入前备份 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 物品封面图片缓存及预览工程 | 数据目录中的 `cover-previews` |
| 应用设置 | 数据目录中的 `settings.json` |
| 已记住的压缩包密码 | 本地数据库内，以密文存储 |
| 自定义分类与别名 | 数据目录中的 `categories.user.json` |

卸载只移除程序，素材库和应用数据保留在安装目录之外。
