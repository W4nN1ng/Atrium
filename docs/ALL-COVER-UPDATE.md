# 一键更新全部封面

适用于源码及本机安装版 v0.7.0；GitHub 已发布版本的功能范围以对应发布说明为准。

## 使用

在素材库工具栏点击 **更新全部封面**，任务立即在后台开始。不需要先选中素材，也不用再次点击开始。可以继续浏览；任务状态入口可随时查看进度和结果，关闭结果面板不会停止任务。

“全部”取自主进程中的整个素材库，包含合集成员，不受当前列表分页限制。附属图片、说明等资源不参加拍摄；已删除的素材不会重新出现。按钮旁的范围选项可以只处理当前筛选条件或选中的素材。

- **以前拍过的素材：** 沿用保存的物品、来源、角度和背景，重新生成封面。保存过的 Unity 场景物品仍需原工程在线且空闲。
- **首次设置：** 优先从素材包查找物品。找到唯一明确的候选，且结果完整、没有警告时，直接生成保存并记住关联。
- **多个候选或查找结果不完整：** 放入待选图，继续处理其他素材。查看待选结果后，点击希望采用的图片即可应用，无需再点击生成或保存。
- **商品图或手动上传图：** 自动保留，不被全库任务覆盖。
- **缺少依赖、没有可绘制模型或文件不可用：** 保留原图，列出原因。可修复问题后重试失败项；需要自行选择来源或角度时使用原有编辑封面入口。

候选图片每页最多生成八张。选图完成后进入下一件待选素材；也可以切换素材或翻页。查找、生成和确认都在后台核对素材归属与来源变化，避免把另一件素材的图保存过来。

## 停止与撤销

**停止任务**会中止当前尚未保存的结果，并停止后续项目；已经完成的封面保留。关闭面板与切换页面只影响显示。

**撤销本次更新**恢复本任务开始前的图片和关联，包括之前保存过的角度。若素材随后被手动换图、重新关联或删除，撤销会保留这些新操作，不强行恢复旧状态。撤销所需的图片受缓存引用保护。

同一时间只运行一个封面任务操作。任务记录在当前应用会话中保留最近十项；本版不承诺退出应用后自动续跑。

## 条件与限制

从素材包拍摄需要本机可用的 Unity 2022.3、许可证、GPU 及所需渲染依赖。无需事先打开改模工程，也不会把素材导入改模工程。已有包读取、资源数量、渲染器和着色器支持范围继续适用，详见[完整封面说明](UNITY-COVERS.md)。

首次大量生成可能较慢，进度展示已处理的素材数量，不预测未经测量的剩余时间。纯脚本插件、没有网格或依赖不完整的素材，可能无法生成物品封面。
