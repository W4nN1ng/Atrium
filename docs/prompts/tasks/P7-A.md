# P7-A 仓库治理：编辑/启停/排序/导入导出

> 阶段规格：`../VPM-P7.md`（只读 §4）
> 任务板：`../../VPM-TASKS.md` · 共同规则：`../_COMMON.md` · 架构合同：`../../VPM-ARCHITECTURE.md`
> 前置：P1-E
> 覆盖对账项：C3 / C4 / C5 / C6 / C13
> 建议上下文：≤ 30k tokens

## 目标

- 支持仓库编辑名称/URL、启用/停用、移除、拖拽+键盘排序。
- 支持仓库列表导入/导出（纯 URL/自有格式），去重。
- URL 变更重新抓取；旧缓存按 hash 保留；移除只删索引。

## 不做什么

- 不做请求头/密钥（P7-B）。
- 不做本地包/VCC（P7-C/D）。
- 不做复杂优先级 UI。

## 文件所有权

- 修改：`reposService.ts`、`db/repos`、IPC、UI

- 修改：三语 i18n

## 交付物

- 编辑/启停/移除/排序；排序影响同版本来源优先级。
- 导入/导出仓库列表；去重/坏 URL 错误。
- URL 变更后的重新抓取与旧缓存保留。
- UI：拖拽/键盘、二次确认、错误。

## 施工步骤

1. 先扩展仓储与用例。
2. 实现排序/优先级。
3. 实现导入/导出。
4. 接 UI 与确认。
5. 写排序/去重/URL 变更测试。

## 契约与不变量

- 移除仓库不删缓存/工程。
- 排序稳定，同版本多源按顺序。
- 坏 URL 不进入列表/不覆盖旧条目。

## 测试与证据

- 编辑/启停/移除/排序/导入导出。
- URL 变更重抓取/缓存保留。
- 全量测试/typecheck。

- 仓库治理可独立使用。
- 排序规则有测试/文档。
