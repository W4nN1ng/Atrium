# P8-B 操作记录、诊断导出与配额清理

> 阶段规格：`../VPM-P8.md`（只读 §5、§6）
> 任务板：`../../VPM-TASKS.md` · 共同规则：`../_COMMON.md` · 架构合同：`../../VPM-ARCHITECTURE.md`
> 前置：P4-A
> 覆盖对账项：G3 / G4 / G5 / I3
> 建议上下文：≤ 30k tokens

## 目标

- 把操作 journal 变成用户可看的操作记录；错误码/步骤/时间可查。
- 导出诊断包（版本/状态/操作/用量/错误），不含密钥/请求头/文件内容。
- 缓存/vault/备份用量展示与安全清理；不永久删用户工程文件。

## 不做什么

- 不做更新检查/设置补齐（P8-C）。
- 不自动删旧备份/vault。
- 不把完整日志/路径无脑导出。

## 必读（只读这些）

- `docs/VPM-ARCHITECTURE.md` §5、§8
- `docs/prompts/VPM-P8.md` §5、§6
- `install/journal.ts`、`log/`、`vault/`、`cache/`

## 文件所有权

- 新增：`src/main/vpm/log/`、诊断导出、用量查询
- 新增：IPC/UI（维护区）
- 新增：`tests/vpm/log/*.spec.ts`、`tests/vpm/maintenance/*.spec.ts`

## 交付物

- 操作记录列表/详情（脱敏）。
- 诊断 zip：版本/平台/状态/最近操作/用量/错误；无密钥。
- 用量：cache/vault/backups；清理只清缓存/临时，vault/备份需确认。
- UI 入口与错误。

## 施工步骤

1. 定义诊断字段与脱敏规则。
2. 实现操作记录查询/导出。
3. 实现用量/清理边界。
4. 接维护区 UI。
5. 写脱敏/清理/失败测试。

## 契约与不变量

- 诊断包不含 token/请求头/文件内容。
- 不自动删 vault/备份。
- 清理失败不影响核心。

## 测试与证据

- 脱敏/字段完整/导出可解压。
- 用量/清理/确认/失败。
- 全量测试/typecheck。

## 完成定义

- 用户能导出可支持的诊断包。
- 清理不越界。
- 更新 `docs/VPM-TASKS.md`：该任务标为 done（或按实际状态标 blocked/review）。
- PR 含交接段；未验证项明确写出。
