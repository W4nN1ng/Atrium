## 目标

- 在低配机/大目录/大 manifest/长路径/多仓库下测性能与稳定性。
- 确认 Windows 10/11、长路径、非 NTFS/可移动盘、Unity 版本发现边界。
- 只修性能/兼容问题，不扩大范围。

## 不做什么

- 不承诺未验证的 Unity 版本。
- 不新增跨平台支持。
- 不用“应该可以”代替实测。
