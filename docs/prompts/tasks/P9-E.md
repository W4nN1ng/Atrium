# P9-E 0.9.0 发布与安装版更新

> 阶段规格：`../VPM-P9.md`（只读 §5）
> 任务板：`../../VPM-TASKS.md` · 共同规则：`../_COMMON.md` · 架构合同：`../../VPM-ARCHITECTURE.md`
> 前置：P9-D
> 覆盖对账项：H5 / G8
> 建议上下文：≤ 25k tokens

## 目标

- 准备 0.9.0 发布：版本/说明/已知限制/安装包/校验；确认卸载不删用户库/工程。
- 创建 GitHub Release（用户确认后），上传安装包/便携版，核对页面。
- 更新本机安装版并用工具核实版本。

## 不做什么

- 不静默发布/不跳过确认。
- 不发布未验证构建。
- 不删旧 Release/回退包。

## 必读（只读这些）

- `docs/prompts/VPM-P9.md` §5
- `AGENTS.md` 发布规则
- `tools/gh-release.cjs`、`tools/installed-version.cjs`

## 文件所有权

- 修改：`package.json`/锁文件/README/release body
- 产物：`dist/Atrium-Setup-0.9.0.exe`、portable
- 发布：GitHub Release

## 交付物

- 发布说明（大白话、无内部术语）。
- 安装包/便携版 + 哈希/体积；安装/卸载路径核对（卸载保留用户库）。
- Release 页面核对。
- 本机安装版 0.9.0 核实。

## 施工步骤

1. 跑全量门禁/构建。
2. 写发布说明与已知限制。
3. 构建并核对产物。
4. 经用户确认后发 Release。
5. 更新本机安装版并核实。

## 契约与不变量

- 发布前全部门禁通过。
- Release 不包含密钥/用户数据。
- 安装版更新后可回退。

## 测试与证据

- 安装包静默安装/启动/版本核对。
- Release 资产生成/哈希一致。
- 回退包仍可获取。

## 完成定义

- 0.9.0 正式发布且可回退。
- 本机安装版已更新。
- 更新 `docs/VPM-TASKS.md`：该任务标为 done（或按实际状态标 blocked/review）。
- PR 含交接段；未验证项明确写出。
