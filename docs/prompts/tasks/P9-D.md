# P9-D 回退演练与真机回归

> 阶段规格：`../VPM-P9.md`（只读 §4）
> 任务板：`../../VPM-TASKS.md` · 共同规则：`../_COMMON.md` · 架构合同：`../../VPM-ARCHITECTURE.md`
> 前置：P9-C
> 覆盖对账项：G8 / G9 / I9
> 建议上下文：≤ 30k tokens

## 目标

- 按 `VPM-ROLLBACK.md` 做 L1–L5 演练：停用/安全模式/移走状态/装回 0.8.0/代码回退。
- 验证核心库/工程/数据根在回退后无损；记录证据。
- 在安装版做一次关键路径回归（默认关闭/启用/停用）。

## 不做什么

- 不做新功能。
- 不跳过任何一层回退。
- 不用真实素材库/工程做实验。

## 必读（只读这些）

- `docs/VPM-ROLLBACK.md`
- `docs/VPM-ARCHITECTURE.md` §5、§9
- `docs/prompts/VPM-P9.md` §4

## 文件所有权

- 新增：`docs/VPM-ROLLBACK-EVIDENCE.md` 或报告段
- 修改：回退文档中发现的问题
- 测试：沙盒/安装版回归

## 交付物

- L1–L5 演练记录：命令/结果/截图/耗时。
- 核心库 user_version/表结构不变。
- 数据根/快照/工程回退结果。
- 安装版关键路径回归。

## 施工步骤

1. 准备沙盒与备份。
2. 逐层演练并记录。
3. 验证核心/工程无损。
4. 安装版回归。
5. 写结论/问题。

## 契约与不变量

- 不碰真实数据。
- 回退失败要如实记录。
- 不把“能启动”当“无损”。

## 测试与证据

- L1–L5 全部通过。
- 核心 schema 11。
- 安装版关键路径通过。

## 完成定义

- 回退演练有完整证据。
- P9 发布前门禁通过。
- 更新 `docs/VPM-TASKS.md`：该任务标为 done（或按实际状态标 blocked/review）。
- PR 含交接段；未验证项明确写出。
