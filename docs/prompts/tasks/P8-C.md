# P8-C 设置补齐、更新检查与已知限制

> 阶段规格：`../VPM-P8.md`（只读 §7、§8）
> 任务板：`../../VPM-TASKS.md` · 共同规则：`../_COMMON.md` · 架构合同：`../../VPM-ARCHITECTURE.md`
> 前置：P7-B
> 覆盖对账项：G1 / G2 / G3 / G6
> 建议上下文：≤ 25k tokens

## 目标

- 补齐预发布/隐藏包/数据根/配额/日志/语言等设置项，持久化并影响目录/解析。
- 实现手动更新检查→下载→校验→用户点安装；不静默自更新。
- 把已知差异/未验证项写进 README/DEVELOPMENT 的已知限制。

## 不做什么

- 不做自动更新/遥测。
- 不新增语言（保持 zh/en/ja）；主题沿用现有，紧凑模式可选、不做完整主题系统。
- 不把未实现项写成承诺。

## 必读（只读这些）

- `docs/VPM-ARCHITECTURE.md` §9、§11
- `docs/prompts/VPM-P8.md` §7、§8
- `src/main/vpm/config.ts`、`renderer/vpm/VpmSettings.tsx`

## 文件所有权

- 修改：`config.ts`、设置 UI、i18n
- 新增：更新检查服务/UI（手动）
- 修改：`README.md`/`docs/DEVELOPMENT.md` 已知限制

## 交付物

- 设置项：预发布/隐藏包/配额/日志/语言；持久化/校验。
- 手动更新检查：下载/校验/用户确认；失败可解释。
- 已知限制清单（差异/未验证/不支持）。
- 设置测试与截图。

## 施工步骤

1. 列出设置项与默认值。
2. 接配置/目录/解析。
3. 实现手动更新检查。
4. 写已知限制。
5. 截图/测试。

## 契约与不变量

- 更新不静默/不自动执行。
- 设置写入原子/坏值回退。
- 不承诺未实现能力。

## 测试与证据

- 设置持久化/校验/回退。
- 更新检查成功/失败/取消。
- 全量测试/typecheck。

## 完成定义

- 设置项可用且有三语。
- 已知限制与实际一致。
- 更新 `docs/VPM-TASKS.md`：该任务标为 done（或按实际状态标 blocked/review）。
- PR 含交接段；未验证项明确写出。
