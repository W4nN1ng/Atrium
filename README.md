# Atrium

<p align="center">
  <img src="build/icon.png" width="128" height="128" alt="Atrium 图标">
</p>

**面向 VRChat 创作者的本地素材管理工具。**

Atrium 将素材收集、分类检索和 Unity 导入集中在一个 Windows 桌面应用中。支持整理从 Booth 等平台下载的压缩包、模型、服装、贴图与插件，帮助你在多个模型和工程之间找到需要的资源。

素材分析与分类在本地完成，无需联网或配置在线模型服务。判断不明确的素材照常入库，你可以随时在库里改掉分类。

[下载应用](https://github.com/W4nN1ng/Atrium/releases/latest) · [查看版本更新](https://github.com/W4nN1ng/Atrium/releases/tag/v0.7.0) · [反馈问题](https://github.com/W4nN1ng/Atrium/issues)

> **版本说明：** 当前发布的安装包为 v0.7.0，已包含物品封面与全库一键更新、导入历史、手动数据库备份、Unity 自动连接和 EUC-JP 文件名识别。v0.8.0 的导入手势简化已在本机验证通过并安装，GitHub Release 待确认后发布；届时导入入口改为双击素材卡（合集卡长按 1 秒打开），不再保留常驻的「导入到 Unity」按钮。

## 主要功能

### 收集与整理素材

- 支持拖放、资源管理器「发送到 Atrium」、监视文件夹和目录扫描。
- 支持 ZIP、RAR、7z 和 Unity Package，可识别嵌套压缩包。
- 支持加密压缩包；选择记住密码后，在当前 Windows 账户下加密保存。
- 识别合集、适配模型与版本，同一商品的多个变体可归并展示。
- 支持按分类归档，也可使用索引模式，保留文件原有位置。

### 本地分类与搜索

- 结合文件名、包内路径及内容特征，给出分类建议和判断依据。
- 分类结果在入库前可检查，入库后也能随时调整；已学习的规则用于后续分类。
- 支持拼音、假名、罗马字、模型别名和自定义别名搜索。例如 `shinano`、`シナノ`、`信乃` 可匹配同一模型。
- 提供卡片与列表视图、素材封面及集合管理，便于按模型或用途浏览。

### 与 Unity 配合

- 打开 Unity 2022.3 工程后自动准备连接；缺少连接插件时自动安装，收到 Unity 实际响应后显示已连接。
- 只打开一个可用工程时自动作为导入目标；同时打开多个工程时，沿用你明确选过的运行工程，或在双击导入时选择一次。
- 根据工程与集合的匹配结果自动切换视图；匹配不明确时显示提示。
- 导入前检查资源冲突，支持备份被覆盖的文件；批量导入显示处理进度。
- Unity 处于播放模式或忙碌状态时，导入请求排队等待。
- 素材详情可查看经由 Atrium 导入的工程记录。

### 撤销与维护

- 素材库中的文件删除使用系统回收站，多种库操作支持 `Ctrl+Z` 撤销。
- 归档模式下，分类调整前可预览文件移动和覆盖情况，完成后支持整批撤回。
- 库检查可列出重复素材、相似封面、未登记文件和失效记录。
- 「设置 → 维护」提供索引重建、归并检查等维护工具。

**物品封面、导入历史与备份：**

- **物品封面：** 点击素材库工具栏「更新全部封面」即可在后台补齐缺失封面、更新自动封面；明确的唯一物品自动生成保存，多款物品集中选图，点击图片即可应用。保留商品图和手动上传图，支持停止、失败重试及撤销本次更新。[一键更新说明](docs/ALL-COVER-UPDATE.md)。需要调整角度、背景或改用场景中物品时，可继续使用详情里的「编辑封面」。素材包预览使用本机 Unity 2022.3 的独立工程，并自动寻找已知渲染依赖。[详细封面说明](docs/UNITY-COVERS.md)
- **导入历史：** 在「当前工程 → 导入历史」按工程和批次查看包名、状态，并确认撤回。较新的导入涉及同一资源时，会拦截旧批次撤回；恢复不完整时显示具体提示。
- **数据库备份：** 在「设置 → 维护」选择保存位置，备份素材索引、分类、集合和导入历史。副本不包含素材原文件、缩略图、Unity 工程或导入前文件备份。

界面支持简体中文、English 和日本語。应用可常驻托盘，并通过 `Ctrl+Alt+A` 打开素材投放窗口。

## 下载与安装

前往 [Releases](https://github.com/W4nN1ng/Atrium/releases/latest) 选择一个版本：

| 文件 | 使用方式 |
| --- | --- |
| `Atrium-Setup-0.7.0.exe` | 安装版，推荐使用。安装到当前用户账户，无需管理员权限，提供桌面和开始菜单快捷方式。 |
| `Atrium-portable-0.7.0.exe` | 便携版，可直接运行，无需安装。 |

从 v0.5.0 升级可直接运行安装版覆盖安装。已验证的升级流程保留素材记录、分类和用户修改；素材库位于安装目录之外。

发布包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。请确认文件来自本仓库的发布页；如需继续运行，可在系统提供该选项时选择「更多信息 → 仍要运行」。

## 快速开始

1. **选择素材库。** 新建素材库可选择独立文件夹；已有素材库可选择「接管这个库」，先登记文件，不移动或重命名原有内容。素材库不能使用 Unity 工程目录、工程内部目录、盘符根目录或系统目录。
2. **设置素材来源。** 可指定需要监视的下载文件夹，也可随时手动添加素材。
3. **打开 Unity 工程。** Atrium 会自动发现运行中的 Unity 2022.3 工程并准备连接。连接插件安装到工程的 `Packages` 目录，安装过程不修改 `Assets` 或场景。
4. **选择启动偏好。** 根据需要决定是否开机启动；此选项默认关闭。

向导可稍后继续。配置素材库后，将素材拖入收件箱，检查分类建议并确认入库。需要导入 Unity 时，双击素材卡（或选中后按 `Enter`）；合集卡双击会先列出里面的包并全部预勾，确认后才导。要打开合集本身，长按封面 1 秒（列表里长按整行）。连接尚在准备时会等待，并可取消等待；没有打开工程时会提示打开 Unity。

打开工程只会准备连接，素材始终由你双击或按 `Enter` 发起导入。这次导入及其后续批次会固定到最初确定的工程；途中切换目标不会把已有任务转投别处。

连接状态、重试和高级选项见 [Unity 连接说明](docs/UNITY-AUTO-CONNECT.md)。

## 使用说明与常见问题

**「拿不准就问」是在问 AI 吗？**

这里指的是请你确认分类结果。当前版本使用本地规则与内容分析，在线模型辅助分类尚未接入；设置中的模型相关选项不参与实际分类。

**已有素材库会被自动移动吗？**

选择「接管这个库」时，只登记已有内容，并关闭高置信度自动归档。索引模式保留原始文件位置。后续归档或分类移动以界面预览和确认结果为准。

**Unity 桥接会修改什么？**

自动连接只在运行中的受支持工程里增加缺失的 `Packages/com.avca.bridge`；已有插件直接复用，不会强制覆盖。实际素材导入会写入工程资源，导入前会检查冲突。

连接失败时可在「当前工程」重试或查看详情。高级选项可卸载并停用该工程的自动连接，随后不会立即重装；点击重试可重新连接该工程。「设置 → Unity」可关闭全局自动连接。播放、编译或资源导入期间，已提交的素材导入继续按原有队列等待。

**如何使用保留原包和导入确认设置？**

- **保留原始压缩包：** 关闭后，成功归档的原包进入可撤销暂存区，因此不会立即释放磁盘空间。未成功解压或内容为空时，原包保持原位。
- **导入前确认：** 开启时，无冲突也需要确认；关闭时，无冲突可直接导入。有冲突时始终需要确认。
- **拿不准就问：** 控制分类结果需要人工确认的门槛。v0.4.1 已修复设置未参与实际判断的问题。

**如何撤销或备份？**

库操作可使用相应撤销入口或 `Ctrl+Z`。结果卡上的快捷撤回仅覆盖最近一次批次；按批次查看和撤回请用「当前工程 → 导入历史」，手动备份见「设置 → 维护」。

Unity 撤回依赖对应工程和桥接在线，不能保证恢复后续的手动修改；缺少导入前备份的覆盖内容无法自动还原。数据库备份也不能替代素材和 Unity 工程的文件备份。

**同一商品显示为多张卡片怎么办？**

升级后的归并检查按素材库记录执行，换库后可重新检查。界面会显示处理结果，并提供查看与撤销入口；也可在「设置 → 维护」手动检查跨目录归并和同商品归并。

**拖放后没有添加素材怎么办？**

从浏览器或压缩软件拖出的内容可能没有可读取的本地路径。可先保存或解压到本地，再使用「收件箱 → 选择文件…」，或资源管理器「发送到 Atrium」。

**密码和数据如何保存？**

素材分析在本地进行，不上传素材。记住的压缩包密码以密文保存在本地数据库中，解密依赖当前 Windows 账户和设备；换机、换账户或重装系统后可能无法解密。

**卸载会删除素材吗？**

卸载只移除程序。素材库和应用数据存放在安装目录之外。

## 兼容性与已知限制

- 已验证环境为 **Windows 11 + Unity 2022.3.22f1**；Windows 10 尚未完成实机验证。
- 应用数据默认位于 `C:\Users\你的用户名\AppData\Roaming\A`，暂不提供界面迁移；素材库可选择其他磁盘。
- 无编码标记的文件名可能存在识别歧义。v0.5.0 已增加 EUC-JP 候选，但特别短的纯汉字名称仍需人工核对。
- 导入记录只覆盖经由 Atrium 执行的操作，不能作为 Unity 工程全部资源的清单。撤回后可能保留空目录。
- 重复素材需要手动选择处理，相似检测仅比较封面图。
- 搜索支持已知别名及自定义别名，不提供任意中文名称的日语读音转换，详见 [搜索说明](docs/SEARCH.md)。

真实 Unity 导入、系统热键冲突、资源管理器拖放和跨盘故障场景的验证范围见 [验证记录](docs/VERIFY-UNVERIFIED.md)；物品封面见 [使用说明](docs/UNITY-COVERS.md)，导入历史与备份见 [导入恢复说明](docs/FIXES-2026-10-11-IMPORT-RECOVERY.md)。

## 数据位置

| 内容 | 默认位置 |
| --- | --- |
| 素材原文件 | 你指定的素材库或原始文件夹 |
| 素材索引、缩略图、日志及导入前备份 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 应用设置 | 数据目录中的 `settings.json` |
| 已记住的压缩包密码 | 本地数据库内，以密文存储 |
| 自定义分类与别名 | 数据目录中的 `categories.user.json` |

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+K` | 搜索 |
| `Ctrl+Alt+A` | 打开素材投放窗口 |
| 双击素材卡 | 导入该素材；双击合集卡打开成员面板并全预勾 |
| 长按合集卡 / 列表行 1 秒 | 打开合集（普通素材不会触发） |
| `Enter` | 导入选中资源；选中的是合集卡时打开成员面板 |
| `Shift+Enter` | 打开选中的合集（键盘等价于长按） |
| `Ctrl+Z` | 撤销；光标在输入框中时保留文字撤销 |
| `Ctrl+A` | 全选 |
| `Delete` | 将选中素材移入回收站 |
| `Esc` | 取消选择 |
