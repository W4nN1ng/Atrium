# Atrium

<p align="center">
  <img src="build/icon.png" width="128" height="128" alt="Atrium 图标：黑色圆角方块上一个白色的 A">
</p>

给 VRChat 改模玩家用的素材管家。**Windows 桌面程序，完全离线。**

你大概有过这种时候：想找个眼熟的猫耳，只记得是 Booth 上买的、好像叫 "Shinano" 什么的，
解压出来又不知道塞在哪个文件夹里了。包套包、日文文件名、同一个模型的三个体型、
五六个版本 —— 三年下来就是一团 20 多 GB 的乱麻。

**Atrium 做的事很简单：你把包丢进去，它替你拆开、看清楚里面是什么、归到该在的地方；
之后你打开哪个 Unity 工程，它就自动翻到那个模型的那一格，勾一下就能装进去。**

---

## 它能帮你做什么

**丢进去就行。** 四种放法随你挑：拖进窗口、在文件夹里右键「发送到 Atrium」、
盯着一个下载文件夹自动收、或者叫它去看某个目录。
`.zip` `.rar` `.7z` `.unitypackage` 都吃，包中包也能拆开。

**它真的会打开看。** 不是只看文件名猜。它会翻包里的东西 —— 是模型、是材质、是贴图、
是音效还是插件工具 —— 再告诉你它判断这是什么、有多大把握、为什么这么判断。
拿不准的它不替你拍板：要么停在收件箱等你点确认，要么先入库再挂进「待复核」那一栏，
你瞄一眼、点「标记已复核」就算归队；觉得它分错了，在那张卡上改分类就行。

**一个包里的 17 件，是一张卡，不是 17 张。** 同一个模型的三个体型、五个版本，
会并成一张卡，上面写着「适配模型 ×3 · 版本 ×5」，点开才是一层层的清单。
你手动改过的分类它会记住，下次同类东西不再问你第二遍。

**日文包名不乱码。** 从 Booth 下的那些「束縛チャイナFULLSET.zip」这种名字，
显示和搜索都正常。

**带密码的包会问你要密码。** 勾一下「记住这个密码」，下次再撞见同一个包它自己就试出来，
不用你重新翻聊天记录找密码。

**想搜什么都能搜到。** 拼音、日文、英文互相能搜到同一个东西：打 `shinano`、`シナノ`、
`信乃` 都算。分类的口语叫法也认 —— 打 `yifu` 能找到「服装」。你自己加的别名不用重启就生效。

**改分类是真的把文件搬过去。** 改之前会先给你看一张单子：几个文件、搬到哪儿、会不会盖掉谁。
搬完后悔了可以整批撤回。

**跟 Unity 配合是它的正事。** 你打开某个 Unity 工程，Atrium 会自己翻到那个模型的那一格；
勾几个资源点导入，它会一个一个送进去、告诉你进度。装之前会先检查有没有同名文件会被盖掉，
会盖掉的文件先备份一份。Unity 正在播放模式下不报错，排队等它空闲了自己接着跑。
装错了点「退回」，资源真的从工程里删回去。

**手滑有救。** 删除一律进回收站，不会直接抹掉文件；大部分操作 `Ctrl+Z` 能撤回。

**界面三种语言：** 简体中文 / English / 日本語。

## 下载

去 [Releases 页面](https://github.com/W4nN1ng/Atrium/releases/latest) 下这两个之一：

| 文件 | 是什么 |
|---|---|
| `Atrium-Setup-0.4.0.exe` | **安装版**（推荐）。装到你自己的账户里，不用管理员权限，会在开始菜单和桌面放快捷方式 |
| `Atrium-portable-0.4.0.exe` | **便携版**。双击就解开，想放哪个盘放哪个盘，不想用了整个文件夹删掉 |

**第一次打开会被 Windows 拦一下** —— 因为这是个人项目，没有花钱买软件签名。
看到蓝色的「Windows 已保护你的电脑」时，点 **更多信息 → 仍要运行**，之后就再也不会出现。

<details>
<summary>（可选）想核对下载的文件有没有被改过</summary>

发布页上每个文件都写了一串「SHA-256」指纹。想知道自己手上这份对不对，
在该文件上按住 Shift 右键 → 「复制文件地址」，然后在命令行里敲：

```
certutil -hashfile "刚才复制的地址" SHA256
```

出来的那串和发布页上的一样，就没被动过。不核对也没关系，指纹只是给不放心的时候用的。
</details>

## 第一次打开会问你四件事

1. **素材放在哪儿** —— 只有这一步不能跳过。指个文件夹给它就行。
2. **素材从哪儿来** —— 可以指定一个下载文件夹，以后下的东西自动收。
3. **要不要给 Unity 工程装个小助手** —— 一屏列出它发现的工程，默认全勾，你可以逐个取消。
4. **要不要开机常驻在右下角** —— 选「是」或「否」都算回答过，之后不再问。

中途点「稍后配置」不会被拦住，但左边栏会一直留一条「库还没配好，点这里继续设置」提醒你回来。

---

## 我已经有一个大乱库了，会被它整理走吗

**不会。** 第一步指到「已经有素材」的目录时，它会当场问一句：

- **接管这个库** —— 只把里面的东西登记进目录，**一个文件都不搬、不改名**；
  并且顺手关掉「自动归档」，之后每张卡都要你点确认才动你的文件。
- **当成空库** —— 你想让它重新规划目录结构的话选这个。

想反悔随时能撤。

---

## 那个「小助手」会不会动我的工程

不会。它只是往工程的 `Packages` 文件夹里放一小段传话用的脚本，
**不碰你的 `Assets`、不改你的场景**。不想用了删掉那一个文件夹就干净了。
第一次发现某个新工程时它会先问你一句，你说「不要」它就不动，也不会再骚扰你。

## 常见问题

**它会不会偷偷联网把我的东西传走？** 不会。这程序整个不联网，也不上传任何东西。
它甚至在你没开的时候什么都不干。

**我输入的压缩包密码存在哪？** 存在它自己的数据文件里，用你的 Windows 账户加密过，
只有你这台机器上你这个账户能解开。界面上任何地方都不会把密码显示出来。

**素材库能放别的盘吗？** 能，指哪儿都行。
（它自己的记账文件目前固定在 `C:\Users\你的用户名\AppData\Roaming\A`，
这部分暂时搬不走，素材本体不受影响。）

**改错了怎么办？** 大部分动作 `Ctrl+Z` 能撤回。另外「设置 → 维护」里能备份数据、
重建索引、检查库里的重复项和没登记的东西，还有两个专门收拾旧账的：
「拆开跨目录的归并组」和「把同一件衣服重新并成一张卡」—— 两个都先给你看单子再动手，
都只改它的记账，一个文件都不挪，做完还能整批撤回。

**同一件衣服裂成了好几张卡？** 早期版本对「方括号里写适配模型」这种名字处理得糙，
同一件东西按模型名各分了一张卡。**升级后第一次打开，它自己就把这些旧账并好了**，
并完在最上面跟你说一句「帮你把 N 张其实是同一件东西的卡并到了一起」。
那条不挡路、十几秒自己收起；想看清它动了什么，点那句旁边的「看看改了什么」，
不想让它并可以点「撤销」。想再手动检查一遍，就是上面「设置 → 维护」里那一栏。

**删掉的素材能找回吗？** 删除是丢进系统回收站，不是直接抹掉。你在回收站里还能捞回来。

**一个文件夹里装着几十件不同东西，结果被当成"一套"了？** 看名字。名字里带数量的（`道具22件`、`插件17件`、
`ERP用12件`，或者你随手新建的 `更新`、`重要！`）它就当一个筐 —— 里面的东西一件一张卡，摆在外面能单独找到。
名字写着「合集」「セット」「全家桶」「Big Pack」这种，那是卖家打包卖的一件商品，它照样合成一张卡，不会撕碎。
同一件衣服有好几个素体适配的，也照样是一张卡（哪怕文件夹名字里带了数量）。

**我拖进来的文件夹名字，被里面某个包的名字顶掉了？** 现在不会了：你给的那个名字只要不是乱码/一串数字，
就以它为准。被压在下面的那个包名也没丢，它变成这张卡的一个标签，你照旧能按它搜到。

**把文件夹拖进去一点反应都没有？** 以前确实会一声不吭，现在松手之后一定会说一句：
如果没拿到这个文件的实际位置（从浏览器里拖图片、从压缩窗口里拖一行都会这样），它会告诉你原因，
并给你两个照样能收进去的办法。如果你连那层紫色高亮都没看见过，说明这次拖拽根本没送进窗口 ——
改用「收件箱 → 选择文件…」，或者在资源管理器里右键「发送到 Atrium」。

**Windows 10 能用吗？** 应该能，但我只在 Windows 11 上实测过，不敢跟你保证。

**卸载会不会删了我的库？** 不会。卸载只删程序本身，你的素材和它的记账文件都在安装目录之外。

**快捷键**：`Ctrl+K` 搜索 · `Ctrl+Alt+A` 在鼠标位置弹一个小投放窗（拖文件进去就行） ·
`Enter` 导入选中 · `Ctrl+Z` 撤销 · `Ctrl+A` 全选 · `Delete` 丢回收站 · `Esc` 取消选择

## 现在还不会做的事（说实话）

- **没有软件签名**，第一次运行要你自己放行（上面说了原因）。
- **它自己的数据目录搬不了盘**，素材库可以。
- **一次导入分了好几批的时候，界面上只能退回最后那一批**，前面的批次得从「设置 → 维护」里的账本想办法。
- **从资源管理器真实拖文件夹这一条，我没法自动测**（脚本发起不了一次真实的拖拽）。窗口里能测的都测过了：
  拖进来一定会有那层高亮，拿不到文件位置一定会跟你说清楚为什么。真撞上"啥也没发生"就用
  「收件箱 → 选择文件…」或右键「发送到 Atrium」，然后告诉我 —— 我留了一行内部计数能分清是哪种情况。
- **包里的日文文件名，少数几种编码还是会乱码**（作者换过码页的那一类）。已经找到原因，下一轮修。
- **上面那句"自己把旧账并好"每套素材库只做一次**，做完就在设置里记下来，不会每次开机翻你的库。
  你把素材库整个换到另一块盘（或者指到另一个目录），它会给新库再收拾一次 —— 拦的是"同一批卡被并两遍"，
  不是"这台机器以后再也不收拾"。
  那条告知自己收起之后，撤销的入口只剩 `Ctrl+Z`（还没做别的操作时）和「设置 → 维护」那一栏。
- **退回之后工程里会留下几个空文件夹**（东西删干净了，空目录还在），不影响使用，看着烦。
- **它答不了「我这个工程现在装了哪些东西」**，只能答「Atrium 帮你导过哪几次」。
- **重复的素材它只列出来给你看，不会自动删** —— 删哪一份得你决定。
- **相似封面图只比封面，不比别的图片**。
- **中文名字想用日语读音搜不支持**（打 `sokubaku` 搜不到「束縛」）。这是想清楚之后的取舍，
  理由写在 [docs/SEARCH.md](docs/SEARCH.md)。
- **不会帮你问 AI** ——「拿不准的时候问一下模型」这个功能完全没做。
- 只在 **Windows 11 + Unity 2022.3.22f1** 上真机测过。

## 你的东西都在哪儿

| 内容 | 位置 |
|---|---|
| 你的素材本体 | 你自己指定的文件夹，想搬盘随时搬 |
| 它的记账、缩略图、日志、备份 | `C:\Users\你的用户名\AppData\Roaming\A` |
| 设置（包括库在哪儿、各种开关） | 上面那个文件夹里的 `settings.json` |
| 你记住的压缩包密码 | 同一个数据文件里，加密存放 |
| 你自己加的口语叫法 | 同一个文件夹里的 `categories.user.json`，升级不会丢 |

卸载只删程序，上面这些全在外面。
